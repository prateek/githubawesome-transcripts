# GitHub Awesome repositories

A catalogue of the repositories featured on the GitHub Awesome YouTube channel, with what each video said about them.

## Language

**Repository**:
A GitHub repository featured in at least one video. The site's primary entity; there is one per unique repository however many times it was featured.
_Avoid_: Project, section, chapter

**Mention**:
One appearance of one repository in one video, at one timestamp, with what was said about it there.
_Avoid_: Project, section, entry

**Video**:
One upload on the channel, either long-form (a list of repositories) or a short (a single repository).
_Avoid_: Episode

**Short**:
A video that features a single repository. Its mention is treated like any other.

**Transcript**:
The text of what a video said. It is the source of a mention's wording, not something the site is organised around.

**Feature**:
A mention that introduces a repository or returns to it with something new to say. Features are what "featured N times" counts.

**Recap**:
A mention in a monthly round-up video that repeats a repository featured in the preceding weeks. It appears on the repository's page but is not a feature.
_Avoid_: Roll-up, repeat

**Pitch**:
The one-line written description of a repository, taken from a short's title or from GitHub, never from captions.
_Avoid_: Summary, tagline

**Quote**:
What a video said about a repository in one mention, shown with its date and timestamp.
_Avoid_: Summary, take, chapter text
