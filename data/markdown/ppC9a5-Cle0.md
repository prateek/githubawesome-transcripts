## apple-silicon-accelerometer

[1:03](https://www.youtube.com/watch?v=ppC9a5-Cle0&t=63)

- https://github.com/olvvier/apple-silicon-accelerometer

Your Apple silicon MacBook has a MEMS accelerometer buried inside. Apple never documented a public API. This project reads raw threeaxis acceleration data at around 800 hertz by going directly through IoKit HiHid callbacks to the undocumented Apple SPU sensor. Practical use is vibration detection, but the demo is what gets you. Place your wrists near the trackpad and it uses ballistoc cardiography to estimate your heartbeat from chassis vibrations.

## agent-vault

[7:40](https://www.youtube.com/watch?v=ppC9a5-Cle0&t=460)

- https://github.com/botiverse/agent-vault

When you let an AI agent set up a service that needs an API key, that key flows through the LLM provider servers. Agent Vault prevents that. It acts as a secretaware file IO layer. Agents see placeholders like agent vault open eye key instead of real values. When the agent writes a config file with that placeholder, agent vault substitutes the real secret before it hits disk. When the agent reads the file back, the real value is redacted again.
