## open-orange

[0:10](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=10)

- https://github.com/rivet-dev/open-orange

Open orange is a runtime from Rivet for running Cloudflare workers on your own servers or another cloud. It reads your existing Wrangler config. So orange dev and orange deploy replace the usual commands. Each durable object becomes a rivet actor with its own SQLite database and KVD D1 and rate limiting work as dropin bindings. The team says it can migrate durable objects off Cloudflare with no downtime.

## obsidian-skills

[0:37](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=37)

- https://github.com/obsidianmd/obsidian-skills

Obsidian skills teaches coding agents how to work with Obsidian vaults and their file formats. It covers markdown features like wiki links and callouts bases with filters and formulas and canvas files with connected nodes. Agents can also use the Obsidian CLI to interact with a vault or extract clean markdown from web pages with Defut. The skills work with compatible agents including claude code and codecs.

## ui

[1:04](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=64)

- https://github.com/vercel-labs/ui

UI SDK is a library from Versell Labs for building interfaces from reusable behaviors. Its core handles keyboard navigation, focus, and selection along with interactions like pop-ups and drag and drop including the Arya attributes they need. You combine those behaviors into a component, then render it through an adapter for your framework. It supports React, Vue, Spelvelt, Solid, and Web Components, and includes a skill for coding agents.

## panel

[1:32](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=92)

- https://github.com/serveroshq/panel

Server OS panel is a web dashboard for managing Linux servers across hosting providers. Each server runs a small Damon that connects to the panel where you can deploy apps from Git, configure domains and HTTPS, and inspect resource usage. It also brings backups, uptime alerts, and service logs into one place. Workflows can run on a schedule or a push, and an MCP server lets your assistants work with your servers.

## sand3d

[1:59](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=119)

- https://github.com/Sandflow-ai/sand3d

San 3D is a Python library for building 3D objects as short programs designed for language models to write and people to read. It runs on Blender's Python API with commands for shapes, cuts, and assemblies. Parts, edges, and faces can be referenced by name, and joints describe how components move. You can export the same model as a GB for a viewer, a URDF for robotics, or an STL for printing.

## yogurt

[2:25](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=145)

- https://github.com/FrigadeHQ/yogurt

Yogurt is a meeting notes app for Mac, Windows, and Linux that records your microphone and call audio. It transcribes the conversation and combines it with your own notes to write a summary using models that run on your computer. After downloading those models, transcription and summaries work offline. You can ask questions across past meetings, follow links back to the source, and export your notes as markdown.

## agentes-chat

[2:52](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=172)

- https://github.com/agentes-chat/agentes-chat

Agent's chat is a team chat app you can host yourself where AI agents join channels and direct messages alongside people. Each agent gets a role, an owner, and a budget with access to MCP tools and a computer for running tasks. You can schedule routines or trigger work from events. Actions such as merges and deployments wait for approval in the chat where your team can review them.

## zigzag

[3:17](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=197)

- https://github.com/simpsoka/zigzag

Zigzag is an embroidery editor written in Rust that turns SVG artwork into stitches for embroidery machines. You can adjust paths, thread colors, and stitch settings visually, while built-in checks flag problems like tiny lettering or a design that won't fit the hoop. An MCP connection lets AI agents create and edit designs alongside you. Export machine formats such as PEES and DST or send directly to a Brother sketch over Bluetooth.

## agentrun

[3:46](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=226)

- https://github.com/Parcha-ai/agentrun

Agent Run is a platform for managing agents built with tools like Clawude Code, Codeex, and Open Code. It tracks runs so work can resume after a server restart with approvals and spending caps in one console. After a run, an agent can propose notes, skills, or reusable workflows for review and storage. Future runs start with that saved knowledge, and you can inspect what was kept in the learning tab.

## MiniMax-H3-Image

[5:05](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=305)

- https://github.com/MiniMax-AI/MiniMax-H3-Image

Minia H3 image is Miniax's new model for both generating and editing images in one checkpoint. It outputs around 16 megapixels natively up to 4,96x 4096 without an upscaler. The diffusion transformer has 33 billion parameters and is distilled down to just six sampling steps. That's a lot of pixels for six steps. Editing takes up to 16 reference images and you can serve it locally with diffusers or comfy UI.

## relax

[8:12](https://www.youtube.com/watch?v=vnq7Gq2ZxzY&t=492)

- https://github.com/makepad/relax

Waiting 3 minutes for a Rust build kills any feedback loop. Relax from the MakePad team runs a cargo package straight from source with no RSC c LLVM or linker involved. It compiles each function on first call, optimizes hot code in the background, and patches changed functions into the running program without losing state. The team reports a large 3D game reaching its first frame in 11 seconds on an M4 MacBook.
