## xleak

[0:24](https://www.youtube.com/watch?v=4xTRijqfi5w&t=24)

## No Longer Evil

[1:25](https://www.youtube.com/watch?v=4xTRijqfi5w&t=85)

- https://github.com/codykociemba/NoLongerEvil-Thermostat

Next project is No Longer Evil, and it's all about taking back control of your smart homeware. No Longer Evil is a right to repair firmware and cloud replacement for Nest thermostats. ## ProxyBridge

[2:00](https://www.youtube.com/watch?v=4xTRijqfi5w&t=120)

- https://github.com/InterceptSuite/ProxyBridge

Proxy bridge, a lightweight alternative to Proxifier. Proxybridge gives you transparent proxy routing for any Windows application, even ones that have zero proxy support built in. Thanks to kernel level interception using wind divert, it can capture and redirect both TCP and UDP traffic from specific processes through SOCK 5 or HTTP proxies. Want a game to go through a SOCK 5 proxy, block a background app from touching the internet, and keep your browser direct? Easy.

## OtterLang

[2:31](https://www.youtube.com/watch?v=4xTRijqfi5w&t=151)

- https://github.com/jonathanmagambo/otterlang

Otterlang, a fresh programming language that aims to blend the clarity of Python with the raw performance of native binaries. Otterlang is an indentation sensitive statically typed language powered by an LLVM backend. That means you write code with a clean, readable syntax, but under the hood, it compiles down to fast optimized machine code. It's designed to feel simple, modern, and productive without giving up low-level efficiency. The standout feature, transparent rust, FFI. You can pull in any rust crate and use it directly in Otterlang.

## Datanomy

[3:06](https://www.youtube.com/watch?v=4xTRijqfi5w&t=186)

- https://github.com/raulcd/datanomy

Dataomi, a terminalbased tool designed to help you peel back the layers of your columnar data files and understand what's inside. Data Nomi gives you an interactive anatomystyle view of your data, showing structure, metadata, statistics, and internal layout in a way that's clear, visual, and perfect for developers working with big data formats. Whether you're optimizing storage or just wanting to understand how parquet files are structured on disk, Dataomi gives you a clean interactive breakdown directly in your terminal.

## TinyETL

[3:40](https://www.youtube.com/watch?v=4xTRijqfi5w&t=220)

- https://github.com/alrpal/TinyETL

Tiny ETL, a zero configuration ETL tool packed into a single ultra small binary. Tiny ETL is all about instant data movement and transformation. No dependencies, no config files, no environment setup. You just run one command and it handles the rest. And despite being only 12.5 megabytes, this thing moves data at over 180,000 rows per second, making it ideal for huge data sets and quick pipelines. Tiny ETL is one of the simple ways to move data between formats and databases.

## Toonify

[4:45](https://www.youtube.com/watch?v=4xTRijqfi5w&t=285)

- https://github.com/ScrapeGraphAI/toonify

Tunify, a human readable serialization format that can slash your token usage by 30 to 60%. Tune gives you CSV level compactness, but with real structure, so you're not sacrificing readability or nesting the way you would with raw CSV. It's perfect for passing structured data into LLMs while keeping your context window lean and your API bill under control. It supports full typing, strings, numbers, booleans, plus nested objects, folded keys, and even automatic table formatting for arrays.
