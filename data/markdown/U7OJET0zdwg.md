The day-to-day Node.js tool chain forces you to manage a bloated pile of utilities like Nodeman or NVM. Nub replaces that entire stack with a single Rust binary that runs on top of your existing Node installation. It lets you execute TypeScript directly without any build steps. It also features a faster script runner and autoprovisions node versions on demand with no runtime lockin.
