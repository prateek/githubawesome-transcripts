Welcome back to GitHub Awesome. Today we're looking at 35 self-hosted projects on GitHub. Let's get into it. User tour is a self-hostable alternative to app cues and user flow for building onboarding directly inside your product.

## Usertour

[0:09](https://www.youtube.com/watch?v=COte4lzHcdI&t=9)

- https://github.com/usertour/usertour

You can create guided tours, checklists, launchers, and surveys, then target them using custom user attributes and tracked events. It also keeps versions across staging and production with analytics for views, completions, and drop off points.

## Alexandrie

[0:31](https://www.youtube.com/watch?v=COte4lzHcdI&t=31)

- https://github.com/Smaug6739/Alexandrie

Alexandria is a self-hosted offline first knowledge base that sits between Notion, Obsidian, and Confluence. Its markdown editor handles diagrams, latex, snippets, and interactive elements, while the workspace model adds teams, nested documents, and granular access rules. Permissions run five levels deep per document per user and the PWA keeps working with no connection.

## homelable

[0:55](https://www.youtube.com/watch?v=COte4lzHcdI&t=55)

- https://github.com/Pouzor/homelable

Home label turns a messy Home Lab spreadsheet into an interactive network map with live status built in. It can scan your local network, Q discovered devices for approval and monitor each node through ping, HTTP, TCP or service health endpoints. Proxmox, ziggb, and z-wave imports fill the canvas automatically, while floor plans and custom layouts keep it readable.

## Frontman

[1:19](https://www.youtube.com/watch?v=COte4lzHcdI&t=79)

- https://github.com/frontman-ai/frontman

Frontman is a coding agent that starts from the running browser, then works backward to the source file behind whatever you clicked. It reads the live DOM, computed CSS, component tree, and server logs. So, a request like fixing card spacing comes with context terminal agents usually miss. Changes land in the actual codebase with hot reload and a reviewable diff.

## nylon

[1:43](https://www.youtube.com/watch?v=COte4lzHcdI&t=103)

- https://github.com/encodeous/nylon

Nylon is a self-healing wireguard mesh that keeps traffic moving when links fail without relying on a central coordination server. Nodes exchange routes directly and use measured latency to choose the best multihop path, so machines don't all need direct connectivity. The project targets recovery in under 10 seconds after a failure, while stock WireGuard clients can join through a gateway.

## TuneLog

[2:09](https://www.youtube.com/watch?v=COte4lzHcdI&t=129)

- https://github.com/adiiverma40/tunelog

Tounel log gives Navadrome a recommendation engine that learns from what you actually do instead of asking you to rate every song. Skips lower a track score, full plays raise it, and repeats count even more with recency and discovery mixed into the final playlists. It can also sync your library, improve search with fuzzy matching, and pull collaborative suggestions from listenrains.

## USBridge-Remote

[2:34](https://www.youtube.com/watch?v=COte4lzHcdI&t=154)

- https://github.com/USBridge-Technologies/USBridge-Remote

USB bridge remote puts hardware KVM access and software remote desktop in one client, so the same dashboard can reach a machine before boot or after the operating system loads. The agent handles screen capture and remote input, while Tailscale provides encrypted peer-to-peer networking without manual port forwarding. It also supports moonlight-based streaming and clients across desktop and mobile platforms.

## rocketplaneIO

[3:01](https://www.youtube.com/watch?v=COte4lzHcdI&t=181)

- https://github.com/olemeyer/rocketplaneIO

Rocketplane is a self-hosted AI S sur for Kubernetes that can investigate incidents and apply fixes without handing an LLM unrestricted cubectale access. EBPF tracing map service traffic without changing application code. Then the copilot proposes actions from a fixed risk graded catalog. Each change runs through approval, verification, and automatic roll back. if the cluster doesn't converge.

## compdf-self-hosted

[3:27](https://www.youtube.com/watch?v=COte4lzHcdI&t=207)

- https://github.com/ComPDF/compdf-self-hosted

Comp PDF self-hosted is a Docker deployed document processing platform for teams that don't want files leaving their infrastructure. It puts PDF editing, merging, splitting, encryption, and conversion behind both a browser interface and an API with support for Office files, images, HTML, and structured text formats. The admin console tracks API keys, usage, licenses, and operation logs.

## email-to-print

[3:51](https://www.youtube.com/watch?v=COte4lzHcdI&t=231)

- https://github.com/jfoboston/email-to-print

Email to print turns an ordinary mailbox into a private print queue without routing family documents through a printer vendor's cloud. A small Python service watches a dedicated folder, rejects senders outside your allow list, converts office attachments with Libra Office, and hands printable files to cups. It can even print the email body and send a confirmation afterward.

## midday

[4:16](https://www.youtube.com/watch?v=COte4lzHcdI&t=256)

- https://github.com/midday-ai/midday

Midday brings invoicing, time tracking, receipt matching, and financial reporting into one workspace built for freelancers. If your business admin lives across disconnected tabs and subscriptions, this is the consolidation play. Magic Inbox pairs receipts with transactions, the tracker connects hours to projects, and Vault keeps contracts close to the numbers.

## PortalJS

[4:40](https://www.youtube.com/watch?v=COte4lzHcdI&t=280)

- https://github.com/datopian/portaljs

Portal.js turns a data portal brief into plain editable Nex.js JS instead of trapping you inside a proprietary builder. Its agent skills can recommend an architecture, scaffold the home, catalog, and data set pages, then load CSV, JSON, or GOJSON. A single data provider contract lets the frontend move from static files to CCAN or open metadata without rewriting every page.

## tududi

- https://github.com/chrisvel/tududi

## dashwise

[5:26](https://www.youtube.com/watch?v=COte4lzHcdI&t=326)

- https://github.com/andreasmolnardev/dashwise

Dashwise is a self-hosted home lab dashboard you configure through the interface. So adding services doesn't mean living in YAML. It keeps links, search, and notifications in one start page with widgets for things like weather and bessel. RSS subscriptions can turn the same screen into a compact news reader. Enough monitoring to be useful without pretending to replace your actual observability stack.

## kandev

[5:53](https://www.youtube.com/watch?v=COte4lzHcdI&t=353)

- https://github.com/kdlbs/kandev

Kanddev is a self-hosted control plane for running coding agents in parallel with review built into the workflow instead of bolted on afterward. Tasks live on a canbon board. Each agent gets an isolated git work tree and the workspace keeps code terminals, browser previews, and diffs together. It supports multiple agent providers and local docker or SSH execution.

## 4gaBoards

[6:17](https://www.youtube.com/watch?v=COte4lzHcdI&t=377)

- https://github.com/RARgames/4gaBoards

4GA boards is a self-hosted Canbon app for teams that want realtime collaboration without handing project data to a SAS vendor. Its hierarchy runs from projects down to individual tasks, while collapsible lists keep larger boards readable. You can edit a card and rearrange the board at the same time without losing local description changes. Trello import is built in. Docker compose Postgres behind it.

## diction

[6:43](https://www.youtube.com/watch?v=COte4lzHcdI&t=403)

- https://github.com/omachala/diction

Diction speech to text into a full iOS keyboard, so dictation works inside any app instead of living in a separate recorder. You can run Whisper or Parakeet directly on the phone, point it at any OpenAI compatible transcription server, or self-host the included encrypted gateway. The same keyboard can also compose and rewrite text through custom AI modes.

## Airpipe

[7:07](https://www.youtube.com/watch?v=COte4lzHcdI&t=427)

- https://github.com/Sanyam-G/Airpipe

Airpipe sends files between the terminal and a browser using a short passphrase without setting up SSH accounts or uploading everything to permanent storage. In direct mode, the devices pair through a relay and stream over WebRTC while the relay sees only cipher text. If both sides can't be online together, mailbox mode holds the encrypted file briefly. The same phrase works from CLI, browser, or QR code.

And the logic lives in a clean isolated ranking layer. Uptime kit combines self-hosted uptime monitoring with public status pages. And its real differentiator is distributed probing.

## Rootprint

## ignis
