Emaki is a fully functional static HTTP web server written entirely in pure ARM 64 assembly for Mac OS. No external libraries, no libc, raw Darwin SIS calls directly to Apple silicon. Get, put, delete, bite range requests, custom error pages, directory listing, slow loris mitigation, 48 kilobyte binary, over 1.2 million requests per second on an M3 while barely touching RAM. Technically impressive, existentially motivated, absolutely unhinged.
