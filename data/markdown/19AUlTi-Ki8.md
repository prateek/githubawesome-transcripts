## gabagool

[1:58](https://www.youtube.com/watch?v=19AUlTi-Ki8&t=118)

- https://github.com/friendlymatthew/gabagool

Gabul is a web assembly interpreter written from scratch in Rust. The name is funny. What it does is not. The whole thing is fully snapshotable. Freeze the entire execution state mid-tick, serialize it, spin up new processes from that exact point, and watch them diverge. It also ships with a time travel debugger. If you've spent any time doing low-level systems work, you know how hard this is to pull off.

## Antfly

[2:24](https://www.youtube.com/watch?v=19AUlTi-Ki8&t=144)

- https://github.com/antflydb/antfly

Antfly is a distributed multimodal search engine written in Go. It combines full text BM25 search, vector similarity, and graph traversal all into a single binary backed by the Pebble storage engine and ets library. It even ships with built-in ML inference. You don't need external APIs for embeddings. Antfly handles the entire rag memory pipeline out of the box.
