## no-ai-slop

[1:23](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=83)

- https://github.com/petergyang/no-ai-slop

No AI slop is a writing skill for codecs, claude code, and other agent setups that edits out the habits making machine written pros painfully obvious. It checks for binary contrasts, empty authority claims, dramatic fragments, inflated importance, and more than 20 other patterns. You can ask it to revise a draft or flag suspicious lines with examples. Then it runs its own pass fail checks. Basically, it gives your editor an editor.

## sticker-forge

[1:51](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=111)

- https://github.com/CatsJuice/sticker-forge

Sticker Forge turns plain text or uploaded artwork into a WebGL sticker you can grab and peel. The diecut edge curls under your pointer, revealing a satin back with a shadow projected from the deformed surface. Peel speed also changes the bundled crackle and tear sounds. It ships as an interactive builder plus a framework independent web component. So this oddly satisfying interaction can live inside a normal site without rebuilding the renderer.

## bento

[2:21](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=141)

- https://github.com/nyblnet/bento

Bento is a PowerPoint alternative where the presentation and its editor live inside one HTML file. Open it in a browser, change the deck, then save the same file back with no account or installer. Slides can carry fonts, images, charts, and animations while the document data stays readable JSON. It even supports encrypted collaboration through an optional blind relay. That's a refreshingly portable way to own a presentation.

## justif

[2:48](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=168)

- https://github.com/lyallcooper/justif

Justify paragraph layout to ordinary web pages, fixing the rivers of whites that browser justification often leaves behind. Instead of breaking one line at a time, it evaluates the whole paragraph with the new plus algorithm, then adds hyphenation and hanging punctuation where useful. Unsupported paragraphs simply keep native rendering, which makes this a surprisingly practical typography upgrade.

## kero

[3:16](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=196)

- https://github.com/egoist/kero

KO is a native Mac OS terminal workspace built for developers supervising code across multiple repositories. The terminal stays central while split panes, a file tree, git diffs, and project grouping keep review work nearby without opening a full IDE. It's written in Swift on top of lib ghosty, and the design favors inspectable actions over one-click automation. That makes it especially sensible when AI agents are producing changes faster than you should trust them.

## pireel

## rwx

RWX turns Unix file permissions from a memorized chmod puzzle into an interactive terminal interace. ## claude-thermos

[5:27](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=327)

- https://github.com/izeigerman/claude-thermos

When your agent hands work to a sub agent that runs long, the main conversation's prompt cache quietly expires and the next turn re-encodes the whole history at the full right rate. Claude Thermos sits in front as a local proxy, watches for that idle window, and replays the last request capped at a single token to refresh the prefix. Each session logs what warming cost and what it avoided.

## minisqlite

[7:02](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=422)

- https://github.com/cursor/minisqlite

MinSQLite is a Rust reimplementation of SQLite that stays compatible with the official database file format. So it can open files written by SQLite 3 and write them back. The maintainers report 5,650 tests and no unsafe library code.

## turbo-fieldfare

[8:16](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=496)

- https://github.com/drumih/turbo-fieldfare

Running a 26 billion parameter model normally means owning the RAM to hold all 14 GB of it. Turbo Fieldfare keeps only the shared core and KV cache resident around two and streams each token's experts off the SSD as the router picks them. Custom Swift and Metal kernels the whole way down. No MLX or Llama CPP underneath. The author measured roughly five tokens a second on an 8 GB M2 Air.

- https://github.com/danilo-znamerovszkij/draw-your-font

## FlowBlock

[14:06](https://www.youtube.com/watch?v=KqL-2KEGqxc&t=846)

- https://github.com/Red-EAD/FlowBlock

Block diffusion models decode one block at a time and every block waits for the one before it to finalize. FlowBlock treats that finality as optional. Commits stay in order and each request gets its own wavefront so batched serving stays dense.
