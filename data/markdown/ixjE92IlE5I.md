Bento is a PowerPoint alternative where the presentation and its editor live inside one HTML file. Open it in a browser, change the deck, then save the same file back with no account or installer. Slides can carry fonts, images, charts, and animations while the document data stays readable JSON. It even supports encrypted collaboration through an optional blind relay. That's a refreshingly portable way to own a presentation.
