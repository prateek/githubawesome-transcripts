## IsoBridge

[2:34](https://www.youtube.com/watch?v=RcMECaHflCY&t=154)

- https://github.com/gabyslaw/IsoBridge

ISOBridge, a complete ISO 8583 parser, builder, and forwarder built in. .NET 6. If you've ever touched ISO 8583, the decades old format behind POS transactions, ATMs, and bank switches, you know it's a jungle. Every vendor has its own dialect. The tooling is scattered or proprietary, and debugging messages often feels like reading hieroglyphics. ISOBridge was built to end that pain. It's a fully functional bridge that parses ISO 8583 messages in binary, builds ISO messages cleanly from JSON, and logs every single transaction with full audibility.

- https://github.com/elusznik/mcp-server-code-execution-mode

Next project is a big one for anyone working with model context protocol and hitting token limits or scaling headaches. This is the MCP code execution server and it tackles one of the biggest pain points in MCP today. context bloat.
