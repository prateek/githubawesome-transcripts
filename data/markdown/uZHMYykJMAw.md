## rust-anything

[0:10](https://www.youtube.com/watch?v=uZHMYykJMAw&t=10)

- https://github.com/erkamyaman/rust-anything

Rust Anything helps you move an existing app to Rust one piece at a time. Say a search box feels slow. It profiles the search to find the loop worth moving, then builds a bridge so the rest of the app can keep calling it the same way. You or your coding agent write the rest. The tool replays recorded cases to check the results, then benchmarks both versions.

## trnrt

[0:59](https://www.youtube.com/watch?v=uZHMYykJMAw&t=59)

- https://github.com/RunanywhereAI/trnrt

Tren RT is an open- source LLM inference engine for AWS Tranium 2 serving an OpenAI compatible API from a single Taran 2 instance. It runs GLM 5.3 flash, a 330 billion parameter mixture of experts with fuse decode kernels written in NKI, a prefix cache, and a 1 million token context. On semi analysis's agent X benchmark, the team reports 3.57 million tokens a minute at about 4 cents per million on spot pricing. Data is Replet's self-hosted observability tool.
