## deslop-please

[0:10](https://www.youtube.com/watch?v=Z0xEtyaEg24&t=10)

- https://github.com/deterministic-machines/deslop-please

Deslop please is an opinionated llinter for sloppy code structure written in Rust and built on the ideas in a philosophy of software design. It pushes your code base toward deep modules with narrow interfaces and runs four checks. module cycles, tangles, leaking strruct fields, and shallow modules. An allow list lets you park known issues, and a suggested agent instruction tells coding agents to fix what it flags from first principles.

## vorssaint-utils

[0:39](https://www.youtube.com/watch?v=Z0xEtyaEg24&t=39)

- https://github.com/vorssaint/vorssaint-utils

Vorsaint is a modular Swift menu bar toolkit for Apple Silicon Max that replaces a pile of separate paid utilities. In one app, it bundles a per app volume mixer, window snapping, system monitoring, local clipboard history, offline OCR, and screen recording. Every module is opt-in and removable inside settings, so you only run what you want. Permissions stay optional per feature with no accounts and no telemetry.

## RainGen-RainGenerator

[1:06](https://www.youtube.com/watch?v=Z0xEtyaEg24&t=66)

- https://github.com/AhmadHassan-BTed/RainGen-RainGenerator

Rainen is a procedural rain and thunderstorm simulator in Python with no pre-recorded audio or video loops. It builds wind from filtered white noise, droplet impacts from granular synthesis, and distance-time thunderclaps mixed with soft clipping. Visuals pair three tier parallax raindrops and splashes with branching lightning drawn by midpoint displacement. You can also run it headless from the CLI to export wave files.

## xnulinux

[1:33](https://www.youtube.com/watch?v=Z0xEtyaEg24&t=93)

- https://github.com/AFK-surf/xnulinux

Xn Linux runs Apple's XNU kernel as a loadable module inside unmodified ARM 64 Linux. You pair it with a small interface module that lets Linux lend memory, timers, networking, and GPU access, while XNU drives the CPU and MMU directly. Finder, Safari, and other Mac OS apps run right alongside native Linux processes with no hypervisor or virtual machine.

## rea-games

[1:57](https://www.youtube.com/watch?v=Z0xEtyaEg24&t=117)

- https://github.com/erkamyaman/rea-games

RIA games is an agent skill for porting open- source games to web, rust, or god dot and checking the rebuild frame by frame. It drives the original with an external clock and controlled RNG, then captures the rules and quirks in a gamed MD spec. Replaying that log against the new build feeds any divergence back to the agent until every frame lines up. So far, it's been tested on 2048 and Chrome's offline dyno.
