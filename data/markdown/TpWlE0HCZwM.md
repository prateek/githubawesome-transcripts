## Project NOMAD

[0:10](https://www.youtube.com/watch?v=TpWlE0HCZwM&t=10)

- https://github.com/Crosstalk-Solutions/project-nomad

Project Nomad stands for Node for Offline Media, Archives, and Data. And it's exactly what that sounds like. It's a self-contained Docker orchestrated web server designed to run completely without internet access. Through a single command center UI, you can pre-download full Wikipedia archives, detailed offline maps, survival and medical PDFs, and spin up a local AI assistant powered by OALMA.

## Expect

[0:36](https://www.youtube.com/watch?v=TpWlE0HCZwM&t=36)

- https://github.com/millionco/expect

AI agents write front-end code without any way to verify it actually works in a browser. Expect closes that loop. It's a CLI skill for clawed code that automatically scans unstaged git changes or branch diffs, generates a test plan, and executes it against a real live browser. When your agent finishes building a feature, it tests the UI itself before opening a pull request. Your agent writes the code, checks that it works, then asks for review.

## OpenSpace

[1:05](https://www.youtube.com/watch?v=TpWlE0HCZwM&t=65)

- https://github.com/HKUDS/OpenSpace

Every Claw Code session starts from scratch. Same mistakes, same token burn, no memory of what worked last time. OpenSpace runs alongside your agent and watches it work. When it successfully solves something complex, a weird TypeScript error, or a resilient data service, OpenSpace extracts that logic and saves it as a reusable skill in a local SQLite database. Next time a similar problem comes up, it feeds the solution back instantly.

## feynman

## gea

[2:24](https://www.youtube.com/watch?v=TpWlE0HCZwM&t=144)

- https://github.com/dashersw/gea

Another JavaScript framework, yes, but the benchmarks on this one are hard to ignore. GIA ditches the virtual DOM entirely. Instead of a heavy runtime, it uses compile time.js JSX transforms and proxybased stores for what it calls surgical DOM patching. The key difference from other compiled frameworks like spelt when you change one item in a list GI mutates the proxied array in place and feeds that exact operation straight into a pre-ompiled DOM patcher.

## HyperAgents

[2:53](https://www.youtube.com/watch?v=TpWlE0HCZwM&t=173)

- https://github.com/facebookresearch/HyperAgents

Most self-improving AI systems have a hard-coded meta agent that rewrites task logic. Hyper agents from Metafare goes a level deeper. It unifies the tasks agent and the meta optimizing agent into a single self-referential program embedded in an evolutionary search loop. The system doesn't just rewrite what it does. It rewrites how it self-improves. The optimization mechanism itself is on the table.

Seekite is convenient but you lose Postgress syntax and type system. PG micro closes that gap. ## TurboQuant+

[14:30](https://www.youtube.com/watch?v=TpWlE0HCZwM&t=870)

- https://github.com/TheTom/turboquant_plus

The KV cache memory wall is the hard limit that ends most long local AI sessions. Google research dropped a paper on Turbo Quant, a three-bit compression algorithm that shrinks the KV cache by up to 6x with no accuracy loss. Turboquant Plus is a fork that brings the algorithm to Apple silicon and llama.cpp. CPP using custom metal kernels achieving 4.6x memory compression with no speed penalty. \[music\]
