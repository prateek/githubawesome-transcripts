Free MDU project that cracks open the world of Mle appliance diagnostics. Mle has used a hidden infrared-based optical diagnostic interface on their appliances since the '90s, but accessing it traditionally required an expensive proprietary adapter and closed source tooling only available to certified technicians. Freemdu changes that. This project provides open hardware, firmware, and software that let anyone communicate with these appliances.
