Human Review opens an HTML or markdown file in your browser as an editable document. Fix a sentence yourself. Select a phrase and comment on it. Click an image and comment on that. Delete a section outright. Then hit send and your agent receives every edit and comment as one batch rather than a paragraph of instructions it has to parse. Commandclick links to review several pages before sending. Runs locally. No account, no API
