Any doc converts Word, PowerPoint, Excel, Open Document, RTF, Epub, CSV, and PDF into markdown written in Rust with Node and Python bindings. Every format parses into one shared document model and renders through one serializer. So, a table escaping fix for DOCX fixes RTF and ODT at the same time. Format detection reads the bytes rather than the extension.
