WordPress's plug-in architecture is a 20-year-old security liability. Mdash rebuilds it from scratch in Typescript on Astro and Cloudflare. Plugins run in sandboxed worker isolates. Content is stored as structured JSON, not HTML. It ships with a built-in MCP server, so Claude or Cursor can hook directly into your site to build themes, manage the database, and write content.
