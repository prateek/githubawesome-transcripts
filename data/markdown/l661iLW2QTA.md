## kanzo

[0:10](https://www.youtube.com/watch?v=l661iLW2QTA&t=10)

- https://github.com/emanuele-em/kanzo

Conzo is a conbon board that runs in your browser and doubles as an MCP server. So you and your coding agents share the same task list. Run one command and the board opens on your machine. Your agents connect to it, move cards between columns, and leave comments as they work while you watch and steer. The whole board lives in one folder and syncs between computers through a private git repo you own.

## traccar

[0:37](https://www.youtube.com/watch?v=l661iLW2QTA&t=37)

- https://github.com/traccar/traccar

Trackar is an open-source GPS tracking platform you can run yourself. It speaks more than 200 GPS protocols and works with over 2,000 tracker models, so almost any device can report in. Locations land in your own SQL database, and you follow everything live on a web dashboard or a phone app. You can draw geoences that alert you when a vehicle enters or leaves an area and pull reports on trips and driver behavior.

## suna

[1:05](https://www.youtube.com/watch?v=l661iLW2QTA&t=65)

- https://github.com/kortix-ai/suna

Cordix is a self-hostable platform for running AI agents that do real work for a team built on Open Code agents. Each agent works in its own isolated cloud sandbox on its own git branch. You can hand them tasks from Slack or Microsoft Teams or set them off on a schedule or a web hook. They plug into thousands of apps through connectors and MCP and every tool can be set to allow, ask or block.

## dossier

[1:31](https://www.youtube.com/watch?v=l661iLW2QTA&t=91)

- https://github.com/AienTech/dossier

Dossier is a self-hosted job search app that writes resumes and cover letters tailored to each built with Nex.js and Postgress SQL. You keep one career profile with all your real experience. Paste in a job posting or search job boards and the AI pulls out what the employer wants and shows how well you match. Then it drafts your documents from your profile. You polish them in a chat and export them as PDFs.

## Termix

[3:36](https://www.youtube.com/watch?v=l661iLW2QTA&t=216)

- https://github.com/Termix-SSH/Termix

Termix puts your server connections, credentials, and management tools in one self-hosted workspace. ## AgentFlux

[4:01](https://www.youtube.com/watch?v=l661iLW2QTA&t=241)

## dashbeam

[4:26](https://www.youtube.com/watch?v=l661iLW2QTA&t=266)

- https://github.com/tonyantony300/dashbeam

Dashbeam is an open- source way to send files straight from one device to another with no cloud in between on desktop, Android, the command line, and the web. It's built on IRO, a peer-to-peer networking stack, and every transfer is encrypted with each file checked against its hash. devices find each other with a pairing code, a share ticket, or automatically on your local network.

## alma-relay

[6:05](https://www.youtube.com/watch?v=l661iLW2QTA&t=365)

- https://github.com/yetone/alma-relay

Alma relay is a relay you can host yourself. So the Alma app on your phone can control Alma on your desktop from anywhere.
