## Localflare

[0:18](https://www.youtube.com/watch?v=aBIqbGVLKws&t=18)

- https://github.com/rohanprasadofficial/localflare

If you're building on Cloudflare workers, debugging locally can feel like flying blind. Localflare fixes that. Browse and edit KV namespaces, manage R2 buckets like a file manager, and inspect durable objects without guesswork.

## Smaug

## zpdf

[1:41](https://www.youtube.com/watch?v=aBIqbGVLKws&t=101)

- https://github.com/Lulzx/zpdf

ZPDF is a fast PDF text extraction library. It uses memory mapped parsing to handle massive PDFs with ease. Streaming extraction and multi-threaded page processing means speed without wasted memory. It supports modern PDF features, multiple compression filters, and real font encodings like to Unicode Caps. If you need efficient PDF text extraction without heavyweight dependencies, ZPDF is the one to watch.

## corroded

[2:32](https://www.youtube.com/watch?v=aBIqbGVLKws&t=152)

- https://github.com/buyukakyuz/corroded
