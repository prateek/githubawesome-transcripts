## witr

[0:20](https://www.youtube.com/watch?v=f1p3ngJ400M&t=20)

- https://github.com/pranshuparmar/witr

Ever looked at your system and thought, "Why is this even running?" Meet WIT, short for why is this running? It answers one question and it answers it clearly. Instead of dumping raw output like PS or systemctl, weer explains the cause. What started this process? What's keeping it alive? Point it at a process name or even a port and weer traces everything back to the root in one human readable explanation.

## ml-sharp

[0:47](https://www.youtube.com/watch?v=f1p3ngJ400M&t=47)

- https://github.com/apple/ml-sharp

MLAP is a project for moninocular view synthesis. Sharp takes a single photograph and in less than a second reconstructs a photorealistic 3D representation of the scene. It does this by predicting a 3D Gaussian scene representation using a single feed forward neural network pass on a standard GPU. The generated scene can be rendered in real time. Sharp views at over 100 frames per second, even when moving the camera.

## Agent Skills for Context Engineering

[1:15](https://www.youtube.com/watch?v=f1p3ngJ400M&t=75)

- https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering

Agent Skills for Context Engineering, the trending toolkit that teaches AI agents how to manage their own memory. Instead of just prompt engineering, this project focuses on context engineering, keeping AI focused, efficient, and error-free, even in long sessions. It comes with plug-and-play skills for everything from recognizing when an agent is overloaded to optimizing context by hiding or summarizing irrelevant info.

## Auto Claude

[1:42](https://www.youtube.com/watch?v=f1p3ngJ400M&t=102)

- https://github.com/AndyMik90/Auto-Claude

AutoClaude, an autonomous multi-agent coding framework that plans, builds, and validates software for you. You describe the goal and multiple AI agents handle everything from architecture to implementation and QA. Agents run in parallel, each inside isolated Git work trees, so your main branch stays safe. There's a built-in self- validation loop that catches bugs before you even review the code.

## MicroQuickJS

[2:08](https://www.youtube.com/watch?v=f1p3ngJ400M&t=128)

- https://github.com/bellard/mquickjs

MicroQujs, a JavaScript engine built for embedded systems. It can run JavaScript using just 10 kilob of RAM. Yes, 10. The entire engine fits in around 100 kilobyt of ROM, including the C library, and still delivers quickJS level performance. It supports a lean ES5 style JavaScript with a stricter mode that blocks inefficient or risky code, perfect for firmware and IoT.

## Agent Skills

[2:34](https://www.youtube.com/watch?v=f1p3ngJ400M&t=154)

- https://github.com/agentskills/agentskills

AI agents are powerful, but every platform has its own plugins, prompts, and skills. Agent Skills fixes that. It's an open standard that works like a universal app store for AI agents. You write a skill once, and it works across tools like Claude Code and VS Code. Instead of bloated prompts, agent skills uses progressive disclosure. The agent only loads skill names at first, then pulls full instructions only when needed.

## sqlit

[3:01](https://www.youtube.com/watch?v=f1p3ngJ400M&t=181)

- https://github.com/Maxteabag/sqlit

Skit. Think of it as the lazy git of SQL databases. SQLit is a lightweight terminal UI built for developers who just want to connect to a database and run queries fast without wrestling with CLI flags or config files. You simply run SQLIT, pick a saved connection from the connection manager UI and you're in. Out of the box, it supports a huge range of databases. No adapters required.

## textarea

[4:48](https://www.youtube.com/watch?v=f1p3ngJ400M&t=288)

- https://github.com/antonmedv/textarea

Textteria.mmy, a minimalist text editor that lives entirely in your URL. No backend, no database, no accounts, just one HTML file. ## tinypdf

[5:14](https://www.youtube.com/watch?v=f1p3ngJ400M&t=314)

- https://github.com/Lulzx/tinypdf

Tiny PDF is a minimal PDF creation library that does one thing extremely well. This entire library is under 400 lines of code, weighs just 3.3 kilobytes, has zero dependencies, and still generates real standards compliant PDFs. Compared to something like JSPDF, tiny PDF is nearly 70 times smaller because it intentionally cuts everything you don't need. Just the 95% use case, putting text and images on a page.

## History LLMs

[6:08](https://www.youtube.com/watch?v=f1p3ngJ400M&t=368)

- https://github.com/DGoettlich/history-llms

Ever wish you could talk to the past? Meet history LLMs, timelocked language models trained entirely on historical texts. Ask about 1913 or 1946, and get answers as people of that era actually thought. Unlike modern AI, these models don't roleplay. They embody the textual culture of their time, from newspapers to novels. Curious what educated Europeans worried about before WWI? History LLMs will tell you in their own words.

## TailwindSQL

[6:37](https://www.youtube.com/watch?v=f1p3ngJ400M&t=397)

- https://github.com/mmarinovic/tailwindsql

Tailwind sequel. And this one is different. Tailwind SQL lets you write SQL queries using Tailwind style class names directly inside React Server components. Instead of writing raw SQL strings, you class name your way to database queries. It's built specifically for modern React. Zero client side JavaScript, zero runtime overhead, and queries are parsed and executed at build or render time.

## PortKiller

[7:56](https://www.youtube.com/watch?v=f1p3ngJ400M&t=476)

- https://github.com/productdevbook/port-killer

Port Killer, a tiny Mac OS menu bar app that does exactly what its name suggests, kills processes hogging your ports. If you've ever tried to start a dev server and hit that classic error, port 3000 already in use, you already know the pain. Port Killer lives quietly in your menu bar. No doc clutter, no terminal commands to remember. It automatically scans your system for listening TCP ports and shows you exactly which process in P is using each one.

## TurboDiffusion

[8:26](https://www.youtube.com/watch?v=f1p3ngJ400M&t=506)

- https://github.com/thu-ml/TurboDiffusion

Turbo Diffusion, a project that makes AI video generation fast. It takes models that used to take minutes to create a few seconds of video and speeds them up by 100 to 200 times. ## Durable Streams

[11:04](https://www.youtube.com/watch?v=f1p3ngJ400M&t=664)

- https://github.com/durable-streams/durable-streams

Let's talk about a missing primitive in modern apps. Durable realtime streams for clients. Websockets and SSE look simple until the tab refreshes, the network drops, or the user switches devices. Then everything breaks. Durable Streams fixes this. It's an open HTTP-based protocol for ordered replayable streams with offset based resume. If a client disconnects, it just picks up exactly where it left off.

## zpdf

[12:51](https://www.youtube.com/watch?v=f1p3ngJ400M&t=771)

- https://github.com/Lulzx/zpdf

ZPDF is a fast PDF text extraction library. It uses memory mapped parsing to handle massive PDFs with ease. Streaming extraction and multi-threaded page processing means speed without wasted memory. It supports modern PDF features, multiple compression filters, and real font encodings like to unicode caps. If you need efficient PDF text extraction without heavyweight dependencies, ZPDF is the one to watch.
