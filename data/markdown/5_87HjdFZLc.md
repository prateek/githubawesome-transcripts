Someone was spending over $200 a day on clawed code API credits with no idea where it was going. So, they built a tool to find out. Code burn is a terminal UI that reads your local session transcripts and categorizes every token spent. No LLM calls required. Cost broken down by task type, debugging, brainstorming, actual coding, plus token overhead from bloated MCP servers. Interactive daily activity chart and a Mac menu bar widget included.
