## iris

[0:11](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=11)

- https://github.com/brijr/iris

Iris is a screenshot CLI that also runs as an MCP server from the same binary. So an agent calling capture gets the image in line instead of a file path to locate. It drives your installed Chrome over DevTools protocol and waits for fonts and image loads before firing. scroll triggering lazy content on full page shots. Retina by default with a documented fallback past Chrome's 16k pixel render limit.

## Wake

[0:37](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=37)

- https://github.com/iAmCorey/Wake

Wake gathers local coding agent histories from clawed codecs and others into one native Mac OS window. It indexes transcripts with SQLite full text search watches for new sessions, renders tool calls and highlighted code and can reopen supported conversations in the original project directory. Agent stores are readon, credentials are skipped, and no network requests are made.

## Maka

[1:03](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=63)

- https://github.com/apache/maka

Apache Macaka is a local first agent workspace where every model message, tool call, result, permission, decision, and termination event becomes an appendon runtime log. Desktop, terminal, CLI, and evaluation runs all pass through the same execution host. So sessions can branch, recover, and compact context without discarding recorded evidence. It supports cloud or local models and permission gated tools.

## threeui

[1:29](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=89)

- https://github.com/MengTo/threeui

3UI community is a login-free catalog of interactive React and 3JS components with the actual implementation sitting beside each live preview. You can browse effects, adjust their controls, switch variants, inspect source, and run the entire catalog locally with Vite. The public repository preserves the main products responsive shell and themes, but removes authentication, checkout, and every pro or beta component.

## openbot

[1:56](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=116)

- https://github.com/CopilotKit/openbot

Openbot gives each agent its own container with its own Chromium login, and workspace, so two co-workers aren't sharing a browser profile. Every tool call routes through one gateway that resolves the target, checks it against your rules, writes an audit row, and only then acts or refuses and names the rule. any AGUI endpoint plugs in. It's alpha, ships with O disabled, and needs a copilot kit intelligence license to run.

## MangoDisk

[2:23](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=143)

- https://github.com/harry0703/MangoDisk

Mango disk is a cross-platform disc analyzer and cleaner that defaults to scanning not deleting. Cleanup rules are public and require source checks plus real system validation before release.

## Jixu

[6:21](https://www.youtube.com/watch?v=fwDyOvUOmy8&t=381)

- https://github.com/joe960913/Jixu

Jixu is a TypeScript harness for running one agent inside a durable recoverable thread.
