## engram

[0:40](https://www.youtube.com/watch?v=Fq7YnzT13sA&t=40)

- https://github.com/Gentleman-Programming/engram

If your AI coding agent keeps forgetting everything after its context gets compacted, engram is the fix. It gives your AI persistent memory using a single Go binary with SQLite and FTS5. The agent proactively saves its state after major architecture decisions or bug fixes and can instantly recover its full session state when needed. No more repeating yourself.

## Overstory

[1:04](https://www.youtube.com/watch?v=Fq7YnzT13sA&t=64)

- https://github.com/jayminwest/overstory

Want to run an entire team of AI agents from a single coding session? Overstory does exactly that. One session, a whole swarm

## kula

[4:28](https://www.youtube.com/watch?v=Fq7YnzT13sA&t=268)

- https://github.com/c0m4r/kula

Kula is a self-contained Linux server monitoring tool that reads directly from proc and cis every second. Single Go binary, zero external dependencies, no databases. Serves a real-time web dashboard and terminal boy.
