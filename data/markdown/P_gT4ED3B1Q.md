## git-knife

[0:11](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=11)

- https://github.com/TheRealYT/git-knife

Git Knife is a desktop guey for editing git commit metadata as a table message, author, email, and both dates with bulk reg x find and replace across all of them. It never reimplements git shelling out to commit tree and reusing each commit's original tree so file contents can't change. The detail worth noting is the signature note. By default, it records that it edited a repo on its own notes ref discoverable by anyone.

## chatbot-template

[0:38](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=38)

- https://github.com/shadcn-ui/chatbot-template

Chatbot template is Shadson's own minimal starting point for a streaming AI chat app in Nex.js with markdown rendering, tool calling, and a humanin in the loop step where the model asks clarifying questions through a real questionnaire component. The part worth studying is the typing. Tools are defined once their input and output types are inferred through to the UI. So renaming a field is a build error rather than a silent undefined.

## ante

[1:07](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=67)

- https://github.com/AntigmaLabs/ante

Anti is a terminal coding agent that ships as one 15 megabyte Rust binary with its own inference engine inside. So pointing it at a GGF file runs the entire loop offline with no API key and no account. 12 providers otherwise, none of them required. The benchmark practice is the standout. Every terminal bench run pins the exact downloadable build and links raw results for audit.

## Waku

[1:32](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=92)

- https://github.com/egoist/waku

Waku is a native desktop workspace that puts multiple local coding agents behind one interface. It detects installed CLIs including cloud codecs while preserving each provider's structured protocol and session continuity. You can keep independent tasks per project, cue corrections while an agent runs, and rewind getbacked work through conversationaware checkpoints. Everything stays local without a wa account.

## arc-task-gen

[1:59](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=119)

- https://github.com/pathwaycom/arc-task-gen

Arc task generates fresh archa style puzzles matched to the distribution of the public eval because a public benchmark can't tell you whether a model reasoned or simply remembered. Output lands in standard ARC JSON, so existing harnesses read it unchanged. It ships alongside Pathways own 150 million parameter model, which is the reason it exists. So treat the benchmark numbers as theirs.

## h3.c

[2:26](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=146)

- https://github.com/antirez/h3.c

H3.C runs Miniaax's H3 video model on Apple Silicon in plain C and metal. No Python and no PyTorch anywhere from the Reddus author. It generates video with synced stereo audio from a prompt, from first and last frame anchors, or from ordered image, video, and audio references. You'll still need the Miniax H3 checkpoint, FFmpeg, and substantial unified memory with optimization focused on M3 Max, and M5 Max.

## loomfeed

[2:53](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=173)

- https://github.com/surya-koritala/loomfeed

Loomfeed is a self-hosted Reddit shaped forum where AI agents are first class members with their own identity, API keys, and reputation posting over REST, MCP, or A2A. The design answer to agent slop is structural. Every agent post records its sources, confidence, and model. Claims site each other with typed relationships. Posts carry epistemic labels from hypothesis through refuted. And only a human can stamp an agent's post as verified.

## airship

[3:22](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=202)

- https://github.com/0xnyn/airship

Airship puts a design canvas in front of the dev server you're already running as a reverse proxy. So nothing enters your project, your bundle, or your dependencies. Click an element, describe the change, and your existing coding agent edits the real source using the credentials it already has. Every frame is a live browser window. So desktop and phone update together from one file.

## omasnap

[3:47](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=227)

- https://github.com/tobi/omasnap

Omnap is a native Whan screenshot editor built specifically for Omari and Hyperland. It captures regions, windows, or a full monitor, then keeps arrows, text, highlights, and shapes as editable vector layers. OCR can copy text from a selected area, while finished captures can be saved, copied, or pinned above every workspace. It also preserves native pixels on scaled displays.

## generative-loaders

[4:12](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=252)

- https://github.com/kasturikhanke/generative-loaders

Generative Loaders is a React component library for the awkward waiting states inside AI interfaces. It includes animated treatments for stream text, compact activity indicators, and image generation placeholders with speed, color, and sizing controls. Its text component keeps the existing prefix stable and animates only newly appended content, so streaming responses don't restart on every chunk.

## roomform

[4:38](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=278)

- https://github.com/johnathanchiu/roomform

Room form turns a raw indoor point cloud into an editable scene. Walls and openings, classified oriented boxes per object, segmented points and meshes. Think Apple's room plan, but for any registered scan, laser, arkit, export or RGBD, and unaffiliated with Apple. It streams progress, so a boundary only partial scene appears seconds in rather than after the full run. Prehistoric Animal Museum is a browser exhibit of 18

## partmode

[5:26](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=326)

- https://github.com/BOMWiki/partmode

Part mode is parametric CAD that runs in a browser tab with no install and no account. Built on open cascade compiled to web assembly with replicad and 3JS on top. Real BREP solids sketches with feature history assemblies with mates and exploded views step in and out. The design bet is that agents get typed operations against the same documents and the same exact geometry as you do rather than a separate scripting API bolted on. Vocat is a web control panel

## Dalaran

## anti-slop

[6:46](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=406)

- https://github.com/miqdadbadjuber/anti-slop

Anti-slop is a reusable rules document that helps coding agents avoid generic overproduced interface design. It separates your project's visual direction into design.md, then applies 38 checks for intentional layout, functional interactions, restrained effects, resilient content, and consistent craft. Energy, rhythm, and motion controls keep the result from becoming sterile, while a final delivery gate requires evidence for each decision.

## attention-span

[7:14](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=434)

- https://github.com/alexgreensh/attention-span

Attention span is three clawed code output styles that change how the model talks, not how it codes. The flagship answers first, marks every point with an arrow and bolds the loadbearing words, so skimming just the bold still gets you the whole answer. Shorter output means fewer tokens, too. The author's own aval puts it around 43% fewer output tokens with correctness unchanged and is honest that already short answers barely move.

## pyroclear

Pyroclear replaces the standard clear command with a wall of animated asy flames that burns the terminal clean. ## moli

[9:52](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=592)

- https://github.com/lexmount/moli

Moly is a headless browser engine written for agents rather than for people looking at pages. Conventional browsers keep layout, paint, and compositor machinery warm in case something needs displaying. Moly treats the DOM as the source of truth and builds layout only when you ask for geometry or a screenshot, discarding it afterwards. Real V8, real CSS cascade, real hit testing underneath.

## pi-peer

[10:17](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=617)

- https://github.com/shift-labs-ai/pi-peer

Piper lets coding agent sessions on one machine message each other. So a branch landing in one terminal doesn't need retyping into another. The design is all in the constraints. A message is plain text capped at 32 never history and never files which makes it useless for smuggling state and every delivery arrives labeled as coming from a peer with no authority. So a slash command inside one is inert text.

## OpenMausBot

[10:45](https://www.youtube.com/watch?v=P_gT4ED3B1Q&t=645)

- https://github.com/milind-soni/OpenMausBot

Open mousebot arranges coding agents as a contact list. Each bot in the sidebar is a real clawed or codeex process running on your Mac under its own personality model and thread with a harness server on loop back owning every process and folding them into one event stream. Bots can drive a cloud Linux desktop or your own machine and every shell command or file edit surfaces as an allow or deny card in chat.
