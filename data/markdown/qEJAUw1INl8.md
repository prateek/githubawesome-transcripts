## reader 3

[0:23](https://www.youtube.com/watch?v=qEJAUw1INl8&t=23)

- https://github.com/karpathy/reader3

First up, Reader 3. A self-hosted EPUB reader designed for one simple mission, reading books together with your LLM. It lets you load any EPUB and go through it chapter by chapter, making it super easy to copy, paste, and discuss the text with your favorite model. Perfect for grabbing classics from Project Gutenberg and turning them into an interactive reading session. The creator calls it 90% vibecoded, a tiny take it asis tool meant purely to inspire.

## FreeMDU

[0:53](https://www.youtube.com/watch?v=qEJAUw1INl8&t=53)

- https://github.com/medusalix/FreeMDU

Freemdu, a project that cracks open the world of melee appliance diagnostics. Mle has used a hidden infraredbased optical diagnostic interface on their appliances since the '9s. But accessing it traditionally required an expensive proprietary adapter and closed source tooling only available to certified technicians. Freemdu changes that completely. This project provides open hardware, firmware, and software that let anyone communicate with these appliances.

## Code-Mode

[1:23](https://www.youtube.com/watch?v=qEJAUw1INl8&t=83)

- https://github.com/universal-tool-calling-protocol/code-mode

Code mode, a project for tool calls via code execution. Normally, LLM struggle with complex tool calling, but they're fantastic at writing code. Code Mode embraces that strength by giving your agent just one tool, the ability to execute TypeScript code that already has access to your entire toolbox. Code Mode turns multi-step tool orchestration into a single elegant block of code. Independent benchmarks even show potential cost savings of over $9,500 per year.

## install-nothing

[1:55](https://www.youtube.com/watch?v=qEJAUw1INl8&t=115)

- https://github.com/buyukakyuz/install-nothing

Install Nothing is a tiny Rustbased terminal app that simulates installing well nothing. Run it and you'll get progress bars, fake logs, pretend package lists, the whole installing things vibe without actually changing anything on your system. It's playful and licensed under the extremely permissive do whatever you want with it license. If you love terminal toys, want a fun demo app, or just enjoy confusing your co-workers, Install Nothing is a perfect little Rust project to start.

## Journiv

- https://github.com/journiv/journiv-app

Next up is Jurnive, a self-hosted private journaling app designed for anyone who wants to keep their thoughts, moods, and memories secure and organized. Jourive offers comprehensive journaling features. Track your mood over time, write with prompt-based entries, upload media, and explore insights with analytics. Advanced search lets you find exactly what you're looking for. All wrapped in a clean, minimal UI that keeps the focus on your writing.

## Claudix

[2:55](https://www.youtube.com/watch?v=qEJAUw1INl8&t=175)

- https://github.com/Haleclipse/Claudix

Claudex VS Code extension that brings the full power of Claude code directly into your editor. This extension gives you a gorgeous integrated chat interface where you can talk to Claude, run commands, browse conversation history, and let the model intelligently understand and modify your codebase. It supports multiple Claude models, streams responses in real time, and even handles permissionbased tool access so you stay in control of what the assistant can do.

## Furgit

[3:25](https://www.youtube.com/watch?v=qEJAUw1INl8&t=205)

- https://github.com/runxiyu/furgit

Next up is Fergit, a fast git library written in Go. It's still early in development. Fergit isn't trying to replace the Git CLI. Instead, it's designed as a high performance library for projects like forges, IDE integrations, and custom git tooling. It has no dependencies outside the Go standard library, supports Shaw 1 and Shaw 256, and uses memory mapped IO, delta optimizations, and zero copy techniques to squeeze out serious speed.

## oracle

[3:54](https://www.youtube.com/watch?v=qEJAUw1INl8&t=234)

- https://github.com/steipete/oracle

Oracle, the CLI that lets your agents whisper their toughest questions to a more powerful model and bundle the exact context and files the Oracle needs to answer. Think of it as a repeatable way to hand an assembled prompt plus attachments to GPT 5.1 or GPT5 Pro and get back a focused file response. It handles prompt assembly, file bundling, and session logging for you. So you can just ask the oracle, wait a few minutes, and get freakishly good answers back.

## Talos Proxmox GitOps

[4:25](https://www.youtube.com/watch?v=qEJAUw1INl8&t=265)

- https://github.com/jamilshaikh07/talos-proxmox-gitops

This project combines Proxmox, Talis Linux, and Argo CD into a fully automated pipeline. ## TextOp

## CodexBar

[5:53](https://www.youtube.com/watch?v=qEJAUw1INl8&t=353)

Codex Bar, a Mac OS menu bar app designed to keep your codeex token usage in view at all times. ## DockrTUI

[6:23](https://www.youtube.com/watch?v=qEJAUw1INl8&t=383)

- https://github.com/LuuNa-JD/dockrtui

## pocketeer

[6:53](https://www.youtube.com/watch?v=qEJAUw1INl8&t=413)

- https://github.com/cch1999/pocketeer

Pocketeer, a fast pocket finder for protein structures written in Python using the alphasphere method based on Delona tessellation. Similar to the popular F-pocket, Pocketeer detects binding pockets and cavities with a modern Pythonic interface. It's designed to be flexible, letting you use it as a Python library or a command line tool. And it fully supports biotite atom arrays for seamless integration with atom works.

## FlowFeat

[7:46](https://www.youtube.com/watch?v=qEJAUw1INl8&t=466)

- https://github.com/tum-vision/flowfeat

Flowfeat, a framework for pixel dense embeddings of motion profiles. Flowfeat distills optical flow networks into fine grained task agnostic pixel level representations, providing features that capture motion with high spatial precision and temporal consistency. Dynamic objects stand out and the embeddings scale gracefully with input resolution, making it ideal for highresolution video or complex motion analysis.

## strace-macos

Strace macOS, a system called Tracer for Mac OS built using the LLDB debugger API. Strace MacOss is a lightweight, powerful option, perfect for debugging or performance monitoring without touching SIP.

## VibeThinker

## channels-console

## fastmcpp

[11:11](https://www.youtube.com/watch?v=qEJAUw1INl8&t=671)

- https://github.com/0xeb/fastmcpp

Fast MCPP is a high performance C++ implementation of the MCP. Designed as a native port of Python's FastMPP library, it delivers the same core MCP functionality with C++ speed and a minimal dependency footprint. FastmPP supports multiple transport layers, ST.IO and websocket, and JSON schema validation. Middleware support enables flexible request and response processing, and it integrates seamlessly with MCP compatible CLI tools.
