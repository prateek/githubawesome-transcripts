## 4DAnyone

## microduck

[0:33](https://www.youtube.com/watch?v=46drTvGQ4rU&t=33)

- https://github.com/pollen-robotics/microduck

Microduck is the software brain of a 25cm biped robot that walks using reinforcement learning policies rather than handwritten gates. On a single rock chip chip, a handful of rust dammons run a 50 Hz loop across 15 servos. One owns the motors, one streams the camera over WebRTC, one reads the game pad. Knock it over and it stands back up. Put wheels on and it loads a different brain to roll.
