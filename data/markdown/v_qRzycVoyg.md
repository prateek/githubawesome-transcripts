## splash

[0:11](https://www.youtube.com/watch?v=v_qRzycVoyg&t=11)

- https://github.com/incoai/splash

Running a coding agent on your own Mac sounds great until the model slows everything down. Splash is a local inference engine for Apple silicon that pairs supported models with speculative decoding and custom metal kernels. It serves OpenAI and Anthropic compatible APIs, handles vision and tool calls, and connects to agents like Codeex and Open Code. You'll need an M3 or newer Mac and enough memory for your chosen model.

## coucou

[0:38](https://www.youtube.com/watch?v=v_qRzycVoyg&t=38)

- https://github.com/Louis-CFM/coucou

Cuckoo puts a little animated character named Mochi in your MacBook notch or your Windows taskbar and has it watch your clawed code sessions. You see each step as it happens, approve or deny permissions without switching windows and drop files straight onto it. There's no telemetry and credentials sit in the system keychain. Mochi comes with 28 handcrafted sounds.

## dscode

[1:03](https://www.youtube.com/watch?v=v_qRzycVoyg&t=63)

- https://github.com/qiz029/dscode

Dcode is a terminal coding agent for Mac OS that lets its sessions work together. Its shell persists between turns so background jobs keep running while another terminal can inspect or steer the same session. You can hand work to child agents in separate git work trees and have an independent reviewer check the resulting diff. The same agent also runs from scripts and CI beyond its terminal interface.

## onetake

[1:29](https://www.youtube.com/watch?v=v_qRzycVoyg&t=89)

- https://github.com/feitangyuan/onetake

Ontake is a claude skill for launch videos shot as one continuous camera move where each beat grows out of the last instead of cutting away. It rebuilds your product's UI in HTML from screenshots so the camera can push into any zoom. Motion blur comes from real multis- sample capture across a 180 degree shutter. Every film gets an automatic continuity score before you see it, and anything too cut heavy gets rejected.

## reelmimic

[1:57](https://www.youtube.com/watch?v=v_qRzycVoyg&t=117)

- https://github.com/edenfunf/reelmimic

Real Mimic takes a reference video and breaks down its pacing, framing, colors, and transitions to plan a new 2D animation. You review the storyboard before Claude Code or Codeex agents build shots in parallel with separate agents checking the results. Then you can leave notes at exact moments for revisions. It's designed to borrow technique without reusing the references footage or characters.

## agent-console

- https://github.com/LockedinLabs-AI/agent-console

Agent console is a local dashboard for what your clawed code and codec sessions actually cost. A team can point several machines at one self-hosted hub and only model IDs, token counts, and hashes leave each machine while prompts and file paths stay put.

## jeeves

[3:38](https://www.youtube.com/watch?v=v_qRzycVoyg&t=218)

- https://github.com/PostHog/jeeves

Jeves is built for when an app needs a decision. Route a support ticket, flag urgency, or score a customer's frustration. The 9B model reasons first, then returns probabilities for yes or no, multiplechoice, and rating questions through a Jev compatible API. Post hog has published the weights, training code, and data. There's a trade-off. Full reasoning takes longer and Jeves trails Jev on some knowledge tests.

## claude-motion-design

[5:39](https://www.youtube.com/watch?v=v_qRzycVoyg&t=339)

- https://github.com/howseen-ai/claude-motion-design

Clawed motion design is a skill that builds motion design videos in plain HTML, then captures them frame by frame with playwright and ffmpeg. There's no remotion or gap underneath. Every frame comes from a seek function. Springs are solved in closed form and motion blur comes from blending subframes. It builds a beat map from your music and it detects audio peaks to play sound effects.

## CalcKernel
