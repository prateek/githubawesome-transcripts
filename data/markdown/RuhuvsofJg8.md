## MROffice

[0:11](https://www.youtube.com/watch?v=RuhuvsofJg8&t=11)

- https://github.com/XinaTian/MROffice

Mr. Office publishes six browser editors you can build into your own app from spreadsheets and PDFs to handwriting and code. You can self-host the editors for formats like CSV and markdown. If your app needs to edit Word, Excel, or PowerPoint files, MR Office offers a hosted embed. Your server opens an editing session and the service sends the updated file back when users save.

## Kernarium

[0:36](https://www.youtube.com/watch?v=RuhuvsofJg8&t=36)

- https://github.com/imxieyi/Kernarium

Cararium runs a real Linux kernel natively inside an iOS app with no hypervisor required. Instead of emulating a full machine like UTM or faking the kernel like ISSH, it compiles user mode Linux to ARM 64 machine code and runs guest apps through a multi-core interpreter. It includes Vulcan support and powers the Endarium Android emulator on iPhone and iPad 2.
