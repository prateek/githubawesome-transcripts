## Z80-μLM

[11:01](https://www.youtube.com/watch?v=JG3jV9731e4&t=661)

- https://github.com/HarryR/z80ai

Z80AI is a language model that runs on a CPU from the 1970s. We're talking about the Z80, an 8bit processor with just 64 kilob of RAM. You train the model on a modern computer, then export it as a single binary that runs on real vintage hardware. No GPU, no floating point. It uses extreme optimization, two-bit weights, triagram hashing, and pure 16-bit integer math. It won't replace chat GPT, but it can chat, play 20 questions, and power retro game characters.
