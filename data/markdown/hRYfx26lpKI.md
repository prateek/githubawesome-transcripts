## OpenMemory

[0:21](https://www.youtube.com/watch?v=hRYfx26lpKI&t=21)

- https://github.com/CaviraOSS/OpenMemory

First up, meet Open Memory, the open- source engine that gives your AI memory. Forget stateless chat bots. Open Memory lets your LLM remember user data, emotions, and context over time, just like a real brain. It's self-hosted, framework free, and built for devs who want full control and transparency. No sketchy cloud APIs here. What makes it wild is its hierarchical memory decomposition system. That means one canonical node per memory, no data duplication, and a biologically inspired graph that links everything together.

## toon

[9:00](https://www.youtube.com/watch?v=hRYfx26lpKI&t=540)

- https://github.com/johannschopplich/toon

Meet Tune, short for token oriented object notation. A compact, human readable format that slashes your LLM token usage in half. Think of it as if YAML and CSV had a baby. Optimized specifically for AI context windows. It keeps indentation like YAML for structure, uses CSV style tables for uniform data, and cuts out all the noisy braces and quotes that waste tokens. Just wrap your JSON in encode, and you'll instantly save 30 to 60% of your token costs.
