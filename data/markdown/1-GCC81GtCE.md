## comet

[0:10](https://www.youtube.com/watch?v=1-GCC81GtCE&t=10)

Comet now calls itself Xeron, a local control layer for clawed code, codecs, cursor, grock, Hermes, and Pi. ## apex-inference-chip

- https://github.com/SigmanticAI/apex-inference-chip

Apex is one transformer decoder layer in RTL running Quen 2.5-b on an FPGA. The architectural bet is putting the KV cache codec inside the data path. ## dgit

- https://github.com/littledivy/dgit

DJIT is a git server where each repository is a durable object with its own SQLite database. So there's no origin server and no file system underneath. ## morphnext

- https://github.com/KickNext/morphnext

Morph Next morphs one Flutter icon into another as actual vector geometry without needing a designed animation for each pair.
