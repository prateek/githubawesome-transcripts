## oink

[0:11](https://www.youtube.com/watch?v=nrxB2WWBBi4&t=11)

- https://github.com/oinkvm/oink

Oink is a peer-to-peer software KVM built in Rust for linking Macs and Windows PCs on one desk. You can use the keyboard, mouse, or trackpad on any machine to control the others with no central server. It routes audio across machines, too, so multiple computers can play through one pair of headphones.
