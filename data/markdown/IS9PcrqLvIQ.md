## OpenWorkflow

[5:34](https://www.youtube.com/watch?v=IS9PcrqLvIQ&t=334)

- https://github.com/openworkflowdev/openworkflow

Open workflow provides durable workflows using your existing database without requiring an orchestration cluster like temporal. Each operation wraps in a memoise step. If the server crashes after a step completes, like charging a card, that step won't re-execute on resume. Workflows resume via deterministic replay sleep for seconds or months without resource overhead. Horizontal scaling by adding workers.

## PriceGhost

[6:01](https://www.youtube.com/watch?v=IS9PcrqLvIQ&t=361)

- https://github.com/clucraft/PriceGhost

Works without AI using multiple scraping strategies.
