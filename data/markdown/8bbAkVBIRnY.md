## claudish-to-english

[0:11](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=11)

- https://github.com/gvzdv/claudish-to-english

Clottish to English rewrites Claude code responses into planer language without changing the agents or saved transcript. A display hook buffers the stream, sends the response to a local model by default, then appends or replaces what appears on screen. An optional hook can create simplified markdown copies or overwrite selected files.

## skills

[0:35](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=35)

- https://github.com/emilkowalski/skills

Emil Kowalsski's skills gives coding agents concrete design judgment for interface motion instead of vague instructions like make it feel better. The collection can build animations with deliberate easing and duration, audit existing motion, find places where animation helps, and warn against unnecessary movement. It also covers UI library selection, rapid prototypes, and Apple inspired web design guidance.

## openanalytics

[1:01](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=61)

- https://github.com/OpenLabs-so/openanalytics

Open analytics is a self-hostable web analytics stack that measures traffic and revenue without cookies, fingerprinting, or cross-sight profiles. Visitor identity uses a salted hash that rotates nightly. Raw IP addresses aren't stored, and privacy signals are honored before events are written. Beyond page views, it handles funnels, web vitals, Stripe revenue attribution, exports, live presence, and an MCP server.

## deepseek-harness

[1:28](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=88)

- https://github.com/deepseek-ai/deepseek-harness

Deepseek harness is Deepseek's own agent harness. And its organizing idea is that everything is a plug-in, including the parts most harnesses hardcode. It's built on Cordis, an existing composability framework with a paper behind it rather than a bespoke architecture. Node and npx get you a local web UI on port 380. The readme is refreshingly bare. No feature list, no benchmark table, no claims.

## human-review

[1:54](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=114)

- https://github.com/petergyang/human-review

Human review opens an HTML or markdown file in your browser as an editable document. Fix a sentence yourself. Select a phrase and comment on it. Click an image and comment on that. Delete a section outright. Then hit send and your agent receives every edit and comment as one batch rather than a paragraph of instructions it has to parse. Commandclick links to review several pages before sending. Runs locally. No account, no API key. Booktoskill

## book-to-skill

[2:22](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=142)

- https://github.com/Leutenegger/book-to-skill

converts a technical book or documentation folder into an agent skill that loads only the chapter needed for a question. A local extractor cleans the source. Then the generator builds a compact skill file, chapter notes, glossery, patterns, and quick reference rules. It supports PDFs, EPUBs, office documents, and plain text with OCR required for scanned PDFs.

## asd-ste100-skill

[2:46](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=166)

- https://github.com/danyuchn/asd-ste100-skill

ASD ST100 skill adapts aerospace simplified technical English for instructions that one AI agent must pass to another without clarification. It flags ambiguous words, passive voice, complex tenses, long noun clusters, hedging, and sentences that hide multiple actions, then rewrites them without dropping conditions or scope. Strict mode fits tools and errors, while a looser mode handles technical pros.

## anti-slop

[3:13](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=193)

- https://github.com/dmmulroy/anti-slop

Anti-slop is an opinionated oxalant plugin that rejects TypeScript and JavaScript patterns which discard type evidence. It catches chained assertions, widened values later cast back, broad unknown contracts, unsafe dictionary types, reflective access, and undocumented assertions. It also bans module mocking in favor of explicit dependency seams.

## pdfcn

## tokentab

- https://github.com/wzchav/tokentab

Token tab reads local session logs from claude codeex then turns their recorded token counts into costs by model project day and activity. ## rakazo

- https://github.com/elie222/rakazo

Rockazo is an open- source take on a grost style personal bot. Each bot gets one thread, its own Linux computer with a browser, memory, and scheduled routines reachable from web, desktop or mobile. ## legal-skills

[4:50](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=290)

- https://github.com/gfodor/legal-skills

Legal skills is three agent skills for US utility patent work. a 316 item pre-filing audit, a simulated USPTO examination that runs until two independent examiners clear the same draft, and an adversarial design around test. The discipline is what stands out. Models can't count, so dates, claim counts, and fees run in Python, and an item nobody checked reports as not reached rather than a quiet pass.

## ha.mr

[5:17](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=317)

- https://github.com/p2r3/ha.mr

HAMR shrinks links without storing them in a backend database. Instead, it compresses the URL itself, stripping common patterns, matching domains against Huffmancoded dictionaries, then packing the remainder into a compact character set. For QR codes, it switches to QR's alpha numeric mode to reduce encoding overhead. Everything runs in the browser, so there are no accounts or link records.

## lore

[5:42](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=342)

- https://github.com/hsusul/lore

Lore turns the session files, codecs, and clawed code already leave on your machine into a searchable desktop archive. Readonly adapters connect each conversation to its repository and git history, then store the index in local SQLite without modifying agent files. It even distinguishes commits recorded during a session from repository state observed later.

## eve-software-factory-template

[6:06](https://www.youtube.com/watch?v=8bbAkVBIRnY&t=366)

- https://github.com/vercel-labs/eve-software-factory-template

Foreman is a template for an autonomous software factory. ## MiniMax-Music3

- https://github.com/MiniMax-AI/MiniMax-Music3

Agent safe pipeline keeps an AI agent from approving its own actions. The agent submits an immutable hashed intent. An independent desion policy layer allows, escalates, or blocks it.
