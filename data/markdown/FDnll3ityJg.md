## anatomy

[0:10](https://www.youtube.com/watch?v=FDnll3ityJg&t=10)

- https://github.com/wheresryan22/anatomy

## Husk

[2:17](https://www.youtube.com/watch?v=FDnll3ityJg&t=137)

- https://github.com/Leviidev/Husk

Want to try an Android game on your iPhone? Husk offers two ways. For supported 64-bit games, it runs the game's Android code on the iPhone's processor while translating the graphics, sound, and input around it. For other apps, it can boot a full Android system through QU, though that's slower. Add an APK and launch it full screen. Setup requires sideloading Husk and enabling JIT.

## vegaml

- https://github.com/NandhaKishorM/vegaml

Vega returns type decisions from a small language model without generating any text built on frozen Quen 3.5 models at point8b and 4B. ## iris-3b

- https://github.com/speridlabs/iris-3b

Iris 3B is an open textto image model with three billion parameters that draws every pixel itself with no VAE in between.
