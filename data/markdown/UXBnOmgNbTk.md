What happens to your password manager if you're gone tomorrow? After concussions and a documentary about memory loss, a developer built Rememory, a cryptographic dead man switch using Shamir's secret sharing. You encrypt files, split the key into five shares, and give them to friends. Any three can recover it. Two reveal zero information. Each share is an offline HTML file. No servers, installs, or internet. built to work even decades
