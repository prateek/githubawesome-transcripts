## Introduction

Welcome back to GitHub Awesome. Today we're looking at 35 self-hosted projects on GitHub. Let's get into it.

## TaskView

[0:08](https://www.youtube.com/watch?v=z6QVBXljJwk&t=8)

- https://github.com/Gimanh/taskview-community

Task View is a self-hosted task manager built specifically so you can't get migrated onto someone else's road map. Most self-hosted project tools still nudge you toward their paid cloud tier eventually. This one draws a hard line in its own license against ever becoming a hosted SAS product. Yours or theirs. It ships canbon boards, role-based permissions, web hooks, and an MCP server.

## ConvertX

[0:34](https://www.youtube.com/watch?v=z6QVBXljJwk&t=34)

- https://github.com/C4illin/ConvertX

Convertex is a web app that swallows over a thousand file formats instead of you hunting a different converter for each one. The usual routine is bouncing between five sketchy online converter sites, each one covering only its own narrow slice of formats. This wraps FFmpeg, Image Magic, Pandock, Libri Office, and a dozen other engines behind one upload box. Batch conversion and password protection included.

## birdnet-go

[1:00](https://www.youtube.com/watch?v=z6QVBXljJwk&t=60)

- https://github.com/tphakala/birdnet-go

BirdNet Go turns a cheap USB microphone into a 247 bird identification station. Most bird ID apps want you to record a clip and upload it somewhere. This runs the birdnet model locally against a live sound card feed trained on over 6,500 species and logs every detection straight to SQLite with a web dashboard to browse it. It runs on a Raspberry Pi 3 and a deep detection mode trades speed for accuracy on trickier calls.

## Work-Review

[1:29](https://www.youtube.com/watch?v=z6QVBXljJwk&t=89)

- https://github.com/wm94i/Work-Review

Work review quietly logs your whole workday so you're not staring at a blank daily report trying to remember what you actually did. Every app you open, every site you visit, even window titles get captured locally with optional screenshots and OCR. Nothing leaves your machine. It writes your daily report for you and it plugs straight into clawed code as an MCP tool.

## geopulse

[1:53](https://www.youtube.com/watch?v=z6QVBXljJwk&t=113)

- https://github.com/tess1o/geopulse

Geopulse is a self-hosted Google timeline replacement that turns your own GPS trail into a real timeline instead of a wall of raw coordinates. It pulls location data from own tracks overland trackar or home assistant and automatically classifies it into stays trips and travel modes. Point it at your image library and your photos snap onto the map where they were taken.

## open-connector

[2:18](https://www.youtube.com/watch?v=z6QVBXljJwk&t=138)

- https://github.com/oomol-lab/open-connector

Open Connector is an open-source gateway your agent talks to instead of you handwiring a different SDK for every SAS tool you connect. Usually that means rebuilding OOTH rate limits and error handling from scratch for notion then again for Slack then again for the next one. This ships over 800 providers as pre-built actions with real OOTH 2 and API key handling reachable through MCP HTTP or its own CLI.

## relaticle

[2:46](https://www.youtube.com/watch?v=z6QVBXljJwk&t=166)

- https://github.com/relaticle/relaticle

Relatical is a CRM built so your AI agent is a first class user, not a bolted on chatbot. Most CRM treat AI as a sidebar feature you awkwardly wire in yourself. This ships an MCP server with 30 tools out of the box. So Claude or any agent gets full CRUD over contacts, companies, and deals through a proper schema discovery layer, not scraped screens.

## job-ops

[3:09](https://www.youtube.com/watch?v=z6QVBXljJwk&t=189)

- https://github.com/DaKheera47/job-ops

Job ops is DevOps for your job search. One dashboard instead of 10 browser tabs across LinkedIn, Indeed, and Glass Door. It won't auto apply for you on purpose since recruiters can spot automated applications and it gets you blacklisted. Instead, it scores every listing against your profile, rewrites your CV to match each one, and watches your inbox to auto flag interview invites and rejections.

## AudioMuse-AI

[3:34](https://www.youtube.com/watch?v=z6QVBXljJwk&t=214)

- https://github.com/NeptuneHub/AudioMuse-AI

Audiomuse AI listens to your actual music library and builds playlists from what songs sound like, not what a streaming algorithm assumes you'll like. This runs local sonic analysis with Labrosa and ONX, then clusters similar sounding tracks, generates a playlist from a text prompt like high tempmpo, low energy, and even searches lyrics by theme across 72 languages.

## postlab

[3:58](https://www.youtube.com/watch?v=z6QVBXljJwk&t=238)

- https://github.com/rifkyputra/postlab

Postlab is one TUI that replaces the dozen separate tools you SSH in to run on a bare metal box. Instead of htop in one tab, ufw in another, and docker ps in a third, this single rust binary covers packages, firewall, failtoban, docker or podman, and even cloudflare tunnels and tail scale from one screen. It runs security audits with one-click fixes, and every config change gets a timestamped backup first.

## rejourney

[4:25](https://www.youtube.com/watch?v=z6QVBXljJwk&t=265)

- https://github.com/rejourneyco/rejourney

Rejoui is a session replay tool that captures literally every pixel your app renders, including the GPU layers. Most tools skip mapbox tiles, custom shaders, metal rendered views. Competitors typically show a blank box where those should be. It runs an async capture pipeline that pauses itself during touches and scrolls. So on their own benchmark, it adds just 12.4 milliseconds to the main thread.

## ChatbotX

[4:52](https://www.youtube.com/watch?v=z6QVBXljJwk&t=292)

- https://github.com/ChatbotXIO/ChatbotX

Chatbot X is a self-hosted alternative to Wadi or Manyhat that puts WhatsApp, Instagram, Telegram, and four other channels in one inbox instead of five separate apps and five separate login. The flow builder handles qualification and routing without code, and its AI agents can answer questions or hand off to a human midcon conversation. Everything's also reachable through a CLI and an MCP server.

## Aural

Oral is an AI interview platform that actually conducts the interview, not just schedules or transcribes it. Building a good interview usually means writing every question yourself and reviewing every recording after. Describe the role in plain language and it generates the full interview, then runs it live over chat, voice, or video, adapting its follow-ups to each answer.

## alt-sendme

[5:42](https://www.youtube.com/watch?v=z6QVBXljJwk&t=342)

- https://github.com/tonyantony300/alt-sendme

Alt send me sends a file straight to another device with no cloud storage sitting in between, not even to bounce through. The usual move is dragging a file into Dropbox or Wii transfer and hoping their size limit doesn't bite. This drops your file into a one-time ticket end to end encrypted over quick and your friend just pastes that ticket to start the transfer directly.

## famstack

[6:06](https://www.youtube.com/watch?v=z6QVBXljJwk&t=366)

Famstack turns a Mac studio sitting in your living room into your family's private cloud. No subscription required. Kids photos, voice memos, and documents usually end up scattered across iCloud, some NAS nobody updates, and a drawer of paper. This runs IMIC for photos, paperless NGX for scanned documents with OCR, and a family matrix chat where a local AI bot transcribes voice memos and files receipts.

## code-server

[6:33](https://www.youtube.com/watch?v=z6QVBXljJwk&t=393)

- https://github.com/coder/code-server

Code Server puts the VS Code in a browser tab, not a lookalike, the real editor, extensions, and all. Setting up a consistent dev environment across a laptop, a work machine, and a Chromebook usually means reinstalling everything three times. This runs on a remote server and streams the full IDE to any browser, so your build runs on server hardware while your laptop just renders pixels.

## sencho

[6:58](https://www.youtube.com/watch?v=z6QVBXljJwk&t=418)

- https://github.com/Studio-Saelix/sencho

Seno manages a whole fleet of Docker hosts without giving you Kubernetes to learn first. The usual choice is ssing into each box separately or taking on a full Kubernetes cluster just to get reliability. This gives every node an authenticated API instead of an open socket. Tunnels through NAT with no port forwarding and runs autoheal policies that restart or roll back a broken stack before you'd have noticed.

## Docmost

Docmost is a self-hosted wiki that looks and feels like notion realtime collaboration and all minus the per seat pricing. Confluence gets expensive fast and most open-source alternatives feel like a downgrade the moment multiple people try to edit together. This handles realtime collaborative editing properly and organizes everything into permission spaces and groups instead of one flat page tree.

## jcorp-nomad

[7:52](https://www.youtube.com/watch?v=z6QVBXljJwk&t=472)

- https://github.com/Jstudner/jcorp-nomad

Nomad is a whole media server that lives inside a USB thumb drive. No Raspberry Pi, no power brick. Running Jellyfin on a Pi means dealing with heat, power draw, and a board that's overkill for just streaming to your own devices. This runs entirely on a single ESP32S3, creates its own Wi-Fi hotspot, and streams movies, music, books, and comics straight from an SD card to any browser, multiple people at once.

## slskd

[8:19](https://www.youtube.com/watch?v=z6QVBXljJwk&t=499)

This runs as a Damon or Docker container reachable from any browser token secured and built to sit behind your existing reverse proxy alongside your other self-hosted tools.

## paperless-ngx

[8:46](https://www.youtube.com/watch?v=z6QVBXljJwk&t=526)

- https://github.com/paperless-ngx/paperless-ngx

Paperless NGX turns a shoe box of receipts and a home scanner into a searchable archive. No cloud subscription required. Physical paperwork just piles up because scanning it once still leaves you unable to find anything later. This runs OCR on everything you feed it, tags and auto sorts documents by learned rules and makes years of paper fully text searchable from a browser.

## brainapi2.git

[9:10](https://www.youtube.com/watch?v=z6QVBXljJwk&t=550)

- https://github.com/Lumen-Labs/brainapi2.git

Most AI memory tools just store your old messages and hand back the closest match, which the makers of Brain API call a database, not memory. This builds a knowledge graph instead. Feed it plain sentences and a swarm of agents pulls out who did what, when, and how it connects. Ask a question, it was never directly told, and it answers by walking a traceable path through the graph, not guessing by similarity.

## jabali-panel

Jabali panel is a self-hosted C panel alternative that treats your database as the single source of truth, not a pile of config files that drift out of sync. ## scanopy

## folderhost

[10:29](https://www.youtube.com/watch?v=z6QVBXljJwk&t=629)

- https://github.com/MertJSX/folderhost

Folder host is a self-hosted cloud in one 19 megabyte binary. No PHP, no database server, no dependency chain. Nexcloud gets you there, but the setup alone takes 15 minutes and a stack of moving parts. This is one file. Download it, run it, and you've got real-time collaborative file editing with Monaco chunked uploads for big files and a recovery bin, all backed by SQLite.

## mazzap

## agentic-operator-core

## PulseWeaver

[12:09](https://www.youtube.com/watch?v=z6QVBXljJwk&t=729)

- https://github.com/DiegoGuidaF/PulseWeaver

Pulsewaver closes the door on your self-hosted apps by IP instead of by login screen. The alternative is exposing Jellyfin's login page to the whole internet or making your mom set up a VPN just to watch a show. This sits in front of your reverse proxy and only lets registered devices through with a heartbeat that keeps roaming phones and laptops current as their IP changes.

## Argus

[12:34](https://www.youtube.com/watch?v=z6QVBXljJwk&t=754)

- https://github.com/release-argus/Argus

Argus watches your dependencies for new releases so you're not the last to know a critical patch dropped. GitHub sends you an email digest eventually, but self-hosted tools and internal services give you nothing. Point it at any repo or site on a schedule, and the moment a version tag changes, it fires a Slack, Godify, or Discord notification, or a web hook that can trigger your own deploy pipeline automatically.
