## nao

[0:09](https://www.youtube.com/watch?v=DYRDAJD0-8Q&t=9)

## 2FA

[2:35](https://www.youtube.com/watch?v=DYRDAJD0-8Q&t=155)

- https://github.com/zeropl/2FA

Easy2FA is a browseronly TOTP code generator. Enter your 2FA secret. Get a live six-digit code that ticks down every 30 seconds, and bookmark the URL. The secret lives in the URL fragment, the part after the hash, which browsers never send over the network, so it never touches a server. No account, no app install, no database. Just open the bookmark and your code is there.
