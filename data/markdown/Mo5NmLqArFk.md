## RzWeb

[2:23](https://www.youtube.com/watch?v=Mo5NmLqArFk&t=143)

- https://github.com/IndAlok/rzweb

This is how you reverse engineer binaries without installing anything. Ours is a reverse engineering platform that runs in your browser. It uses web assembly to port the Ryzen framework directly to the client side. Drag and drop an exe or ELF file, view the disassembly, analyze control flow graphs, all 100% local. You can analyze malware or proprietary code without uploading it to some random cloud server.

## Shimmer From Structure

[2:51](https://www.youtube.com/watch?v=Mo5NmLqArFk&t=171)

- https://github.com/darula-hpp/shimmer-from-structure

You know those loading skeletons you see everywhere. Usually you build them by hand. Shimmer from structure looks at your actual component at runtime and generates the skeleton automatically. No maintenance, no duplicate components to keep in sync.
