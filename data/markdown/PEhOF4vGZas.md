## tailslayer

[9:01](https://www.youtube.com/watch?v=PEhOF4vGZas&t=541)

- https://github.com/LaurieWired/tailslayer

DRAM memory refresh stalls have caused unpredictable latency spikes since the 1960s. Nobody fixed it. Lori Wire just did. Tail Slayer is a C++ library that replicates your data across multiple physical DRAM channels, exploiting undocumented memory channel scrambling offsets, so refresh schedules become completely uncorrelated. Then it races both channels against each other in a hedged read. Whichever isn't refreshing wins.
