AI agents default to generating code. Ponytail makes your agent ask whether it should. Before writing anything, the skill forces it to reason like the laziest senior developer in the room. The one who knows the best code is the code you never wrote. Can this be done by deleting something? Reusing what exists, not building it at all? Less code, less surface area, fewer bugs. The senior engineer instinct bottled into a skill.
