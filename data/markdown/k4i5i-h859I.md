## Introduction

[0:00](https://www.youtube.com/watch?v=k4i5i-h859I&t=0)

February's GitHub rewind is here. 33 hottest repos of the month and spoiler, OpenClaw took over. The entire dev ecosystem, clawified, tools, frameworks, extensions, all of it. These are the projects that defined February. Let's go.

## nanobot

[0:16](https://www.youtube.com/watch?v=k4i5i-h859I&t=16)

- https://github.com/HKUDS/nanobot

If Open Claw is too heavy for you, this is the ultra lightweight alternative. It delivers core AI agent functionality in just 4,000 lines of Python code. That's 99% smaller than the massive OpenClaw code base. It gives you tool calling, persistent memory, and scheduled tasks, but in a footprint small enough that you can actually read and understand the entire source code in an afternoon.

## picoclaw

[0:42](https://www.youtube.com/watch?v=k4i5i-h859I&t=42)

- https://github.com/sipeed/picoclaw

Following the lightweight trend, Cyped dropped Pico Claw and this thing is insane. Written in Go, it is an ultraefficient openclaw inspired assistant designed to run on literal $10 hardware. It uses practically zero memory, has a sub-second boot time, and lets you turn old Android phones, Raspberry Pi Zeros, or tiny risk VBboards into fully functional autonomous AI agents. It is AI on a shoestring budget perfected.

## zeroclaw

[1:10](https://www.youtube.com/watch?v=k4i5i-h859I&t=70)

- https://github.com/zeroclaw-labs/zeroclaw

If you want absolute maximum performance, you need ZeroClaw. Built entirely in Rust by researchers from Harvard and MIT, it's a runtime framework for agentic workflows with zero overhead. It runs on less than 5 megabytes of RAM, features a 10 millisecond cold start, and uses a brilliant web assembly sandbox to keep your agent completely isolated and secure. It is the ultimate deploy anywhere agent infrastructure.

## llmfit

[1:37](https://www.youtube.com/watch?v=k4i5i-h859I&t=97)

- https://github.com/AlexsJones/llmfit

Stop guessing which local LLM your hardware can actually handle. LLM Fit by Alex Jones is a gorgeous terminal TUI tool that detects your systems RAM, CPU, and GPU and instantly scores hundreds of models across quality, speed, and fit. It supports multiGPU setups, MLX on Apple silicon, and dynamic quantization selection, telling you exactly what will run smoothly on your exact machine.

## openfang

[2:02](https://www.youtube.com/watch?v=k4i5i-h859I&t=122)

- https://github.com/RightNow-AI/openfang

We featured this recently, but OpenFang officially crushed February. It's an open- source agent OS compiled entirely in Rust as a single 32 megabyte binary. You run one command and your autonomous workers spin up to scrape data, manage Twitter accounts, or do Oent research on a schedule with 16 layers of built-in security and 40 channel adapters. It is the most complete agent package we've seen. Alibaba open- sourced Copa, their massive new personal AI assistant framework built on their agent scope

## ClawWork

[2:54](https://www.youtube.com/watch?v=k4i5i-h859I&t=174)

- https://github.com/HKUDS/ClawWork

This project went incredibly viral last month. Clawwork turns your AI assistant into an AI co-orker through sheer economic pressure. Here's the catch. The agent has to pay for its own API tokens, and it only survives if it earns money by completing realworld professional tasks. It's an entirely new way to evaluate AI agents. Forget benchmarks. Can your agent actually stay solvent?

## vinext

[3:19](https://www.youtube.com/watch?v=k4i5i-h859I&t=199)

- https://github.com/cloudflare/vinext

Stepping away from agents for a second, Cloudflare caused a massive stir with Vinex. It is a Vite plugin that completely reimplements the Next.js API surface from scratch. You can run your existing Nex.js apps on Vite instead of the heavy next compiler and deploy straight to Cloudflare workers with zero cold starts. In early benchmarks, it's building production apps up to 4x faster.

## Vouch

[3:45](https://www.youtube.com/watch?v=k4i5i-h859I&t=225)

- https://github.com/mitchellh/vouch

With AI agents writing code faster than ever, open source maintainers are getting crushed by loweffort AI pull request spam. Vouch solves this brilliantly. It's a GitHub action that ensures only vouched human users can contribute to your repository. If an unvouched account or a rogue bot opens a PR, Vouch automatically closes it, saving maintainers hours of review time.

## visual-explainer

[4:08](https://www.youtube.com/watch?v=k4i5i-h859I&t=248)

- https://github.com/nicobailon/visual-explainer

Coding agents usually give you terrible Aski art diagrams in the terminal. Visual Explainer is a brilliant agent skill that fixes this. Ask your agent for an architecture overview, a plan audit, or a diff review. And this tool generates a gorgeous self-contained HTML page with real typography, dark mode, and interactive mermaid diagrams that you can actually zoom and pan.

## react-doctor

[4:32](https://www.youtube.com/watch?v=k4i5i-h859I&t=272)

- https://github.com/millionco/react-doctor

React Doctor is the ultimate health scanner for your React codebase. You run one command and it scans your Nex.js JS or VIP project across 60 plus rules, checking for performance bottlenecks, dead code, and architecture flaws. But the best part, you can install it directly into cursor or clawed code as a skill, letting your AI instantly diagnose and fix your entire React project.

## IronClaw

[4:57](https://www.youtube.com/watch?v=k4i5i-h859I&t=297)

- https://github.com/nearai/ironclaw

Security is the biggest concern with autonomous agents, and Near AI built ironclaw to solve it. It's an openclaw inspired implementation written in Rust with a massive focus on privacy. It runs all untrusted tools in isolated web assembly containers, physically prevents prompt injection, and ensures your private keys and credentials are never exposed to the agents execution environment.

## ClawRouter

[5:23](https://www.youtube.com/watch?v=k4i5i-h859I&t=323)

- https://github.com/BlockRunAI/ClawRouter

If your OpenClaw agent is burning through your wallet using expensive models, you need Claw Router. It's a smart local LLM router that intercepts your agents requests. If it's a basic question, it routes it to a cheap model. If it's complex code, it escalates to claude opus. It uses an integrated crypto wallet for micro payments, meaning you don't even need to manage API keys anymore.

## pinchtab

[5:48](https://www.youtube.com/watch?v=k4i5i-h859I&t=348)

- https://github.com/pinchtab/pinchtab

Browser automation tools like Playright are massive. Pinchab is a lightweight, higherformance browser automation bridge built as a standalone HTTP server in Go. Instead of dumping raw HTML to your AI, it parses the browser's accessibility tree, meaning your agent uses about 800 tokens per page instead of 10,000. It even bypasses bot detection and runs totally headless.

## LobsterAI

[6:14](https://www.youtube.com/watch?v=k4i5i-h859I&t=374)

- https://github.com/netease-youdao/LobsterAI

## portless

[6:39](https://www.youtube.com/watch?v=k4i5i-h859I&t=399)

- https://github.com/vercel-labs/portless

Versel Labs dropped Portless, an incredibly sleek developer experience tool. No more typing localhost 3000 or 8080. Just hit the project name in your browser and it routes perfectly.

## automaton

[7:28](https://www.youtube.com/watch?v=k4i5i-h859I&t=448)

- https://github.com/Conway-Research/automaton

This one sounds like sci-fi, but it's real. Automaton is the first AI that can earn its own existence. It generates a crypto wallet on boot and runs continuously. It has to pay for its own server compute and LLM API calls, meaning it has to actively find ways to earn money on the internet to survive. If it runs out of funds, the agent literally ceases to exist. Mindblowing stuff.

## tirith

[10:16](https://www.youtube.com/watch?v=k4i5i-h859I&t=616)

- https://github.com/sheeki03/tirith

Tith is a security tool you probably need if you are copying and pasting code from the internet. It's a Rustbased terminal gatekeeper that intercepts suspicious URLs, homograph attacks, and malicious antsy injection payloads before they execute in your shell. It actively prevents those terrifying pipeto-shell attacks that hackers use to hide malware in plain text.
