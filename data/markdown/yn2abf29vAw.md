## shaders

[0:11](https://www.youtube.com/watch?v=yn2abf29vAw&t=11)

- https://github.com/shader-effects-inc/shaders

Shaders makes WebGPU effects feel like ordinary UI components. Drop in a gradient, glass effect, distortion, or cursor trail. Then stack and blend them without writing the shader yourself. The same library works with React, Vue, Spelt, Solid, and Plain JavaScript. There's also a visual editor. Tune an effect on a canvas, then export the component code straight into your project.

## RemoveMacAI

[0:35](https://www.youtube.com/watch?v=yn2abf29vAw&t=35)

- https://github.com/omlahore/RemoveMacAI

Remove MacA gives you a single place to quiet down Mac OS. On supported Apple Silicon Max, it can switch off selected Apple Intelligence features, remove their downloaded models, disable analytics and personalized ads, and clean up old files taking up space. There's a native app and a command line tool, and you review changes before applying them. If you change your mind, it keeps an undue history.

## SCSKiller

[1:01](https://www.youtube.com/watch?v=yn2abf29vAw&t=61)

- https://github.com/BlueHeisenberg/SCSKiller

SCS Killer tackles that annoying PC gaming hitch when a game compiles a new shader midplay. It scans a supported game shaders and pre-ompiles likely pipelines into your Nvidia or AMD driver cache before you launch. It finds games across major launchers and can rebuild the cache after a driver update. It won't cure every stutter, but it targets shader compilation stalls directly.

## bloodborne\_pc

[1:26](https://www.youtube.com/watch?v=yn2abf29vAw&t=86)

- https://github.com/deadinside28/bloodborne_pc

BBport is an experimental way to run Bloodborne on Linux using your own PS4 game dump. It runs the game's x8664 code directly on the PC, replaces the PlayStation system calls it needs, and translates its graphics to Vulcan. There's a launcher, gamepad support, unlocked frame rates, and FSR upscaling. It's already playable in tested areas, though a full playthrough hasn't been verified. GDPs tackles a dangerous little mistake.

## gdp-ts

[1:52](https://www.youtube.com/watch?v=yn2abf29vAw&t=112)

- https://github.com/rauchg/gdp-ts

checking permission in one line, then forgetting to connect that check to the action it protects. In this TypeScript library, sensitive functions require a proof that a specific user can act on a specific resource. Pass the wrong proof, or none at all, and the code won't type check. A llinter guards against forged proofs, and a companion skill shows coding agents how to use the pattern.

## tendedero
