Sending a bundle of PDFs usually means a zip file and now previewing, reordering, or printing the thing is someone else's problem. PDFX keeps the bundle as one valid PDF. Any normal viewer shows every page in order, but the PDFX desktop app reads the embedded JSON manifest and splits it back into the original documents. Drag PDFs in. Reorder strips. Remove files.
