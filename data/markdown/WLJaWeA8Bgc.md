Building a slide deck in PowerPoint is a great way to lose a whole day to manual formatting and pixel pushing. PPT Master is a clawed skill that builds full presentations from a single prompt. It reads your raw spec file to structure the slides, then writes Python code to generate the actual deck. Because it uses the Python PPTX library, every single element in the final output is fully editable.
