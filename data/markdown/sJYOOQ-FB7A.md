Self-arning skills is a meta skill that teaches your agent to recognize when it just earned a hard one golden path and save it where the tool autoloads it next time. A new skill file, a cursor rule, an agents.mmd entry, whatever fits. It captures deadends, too, since knowing what not to try again is worth as much as the win. It triages what's worth keeping so your config doesn't bloat with oneliners.
