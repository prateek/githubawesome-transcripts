## Agent Skills

[0:11](https://www.youtube.com/watch?v=keillCm88ZY&t=11)

- https://github.com/MengTo/Skills

Mentos skills is a skill library written for the design side of front end, not general coding. Ask an agent for a pricing page or a Gap animation and it improvises, missing the conversion patterns and cleanup habits a real designer already knows. This bakes those in as reusable files. a UI prompting system plus procedural skills for three, JS, Tailwind, and effects like progressive blur and alpha masking.

## ax

[0:38](https://www.youtube.com/watch?v=keillCm88ZY&t=38)

- https://github.com/yusukebe/ax

Axe is an AI era curl that gives coding agents structured page data instead of a raw HTML dump. You know the loop. Curl returns an empty response. The agent shoves thousands of markup tokens into context. Then a regx parser collapses after one CSS tweak. Axe always reports status and headers. maps page structure with a outline and locate, then extracts rows or tables with selectors.

## lingbot-world-v2

[1:03](https://www.youtube.com/watch?v=keillCm88ZY&t=63)

- https://github.com/Robbyant/lingbot-world-v2

Lingbot World-V2 is a generative world model built for long interactive video worlds, not another clip generator that falls apart after a few seconds. The real-time variant targets 720p at 60fps and pilot plus director agents plan actions while adding new scene elements.

## spacewasm

[1:31](https://www.youtube.com/watch?v=keillCm88ZY&t=91)

- https://github.com/nasa/spacewasm

Spacew is NASA's web assembly interpreter for flight software built for constrained hardware where a normal WAMOM runtime has too many memory surprises. Spacewom decodes and validates modules in one streaming pass, converts bite code into an interpretation friendly IR and uses fixedsize allocation pages with no panic on allocation failure. It's was shaped by spacecraft rules.

## os-taxonomy

[1:56](https://www.youtube.com/watch?v=keillCm88ZY&t=116)

- https://github.com/withmarbleapp/os-taxonomy

Marble skill taxonomy maps what a child learns across primary school as a connected graph, not the usual flat list of standards. This breaks it into 1,590 teachable micro topics, each with an age range and evidence for mastery, then wires 3,221 prerequisite edges between them, so you can trace everything a kid must grasp before, say, apparent brightness of stars. Every topic links back to the real standards it came from.

## opendisplay

[2:25](https://www.youtube.com/watch?v=keillCm88ZY&t=145)

- https://github.com/peetzweg/opendisplay

Open Display is a self-hosted Sidecar alternative that turns an iPhone or iPad into a real second Mac monitor instead of a paid subscription or a hardware dongle. ## homerail

[3:44](https://www.youtube.com/watch?v=keillCm88ZY&t=224)

- https://github.com/xiaotianfotos/homerail

Home rail turns throwaway agent chats into auditable, replayable workflows that run on your own home server. A chat session is a black box.
