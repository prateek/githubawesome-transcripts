## Introduction

Today we're reviewing the hottest GitHub repositories of November. From AI to self-hosted tools, this month was absolutely stacked. Let's get started.

## LLM Council

[0:10](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=10)

LLM Council, a project that basically turns your favorite AI models into a panel of experts. Instead of asking just one LLM for an answer, this tool sends your question to multiple models at once through Open Router, lets them respond individually, then has them critique and rank each other, all before a designated chairman LLM pieces everything together into one final refined answer. It's like hosting a mini AI debate inside your browser.

## reader 3

[0:39](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=39)

Reader 3, a self-hosted EPUB reader designed for one simple mission, reading books together with your LLM. It lets you load any EPUB and go through it chapter by chapter, making it super easy to copy, paste, and discuss the text with your favorite model. Perfect for grabbing classics from Project Gutenberg and turning them into an interactive reading session. The creator calls it 90% vibecoded, a tiny take it asis tool meant purely to inspire.

## gitlogue

[1:09](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=69)

Git log. It turns your git history into a cinematic animated replay right inside your terminal. Instead of scrolling through raw commits, GitLog lets you watch your project evolve with realistic typing animations and file changes. Almost like your codebase is telling its own story. It supports tree sitter syntax highlighting across 26 languages, shows a live project file tree with change stats, and even includes a screen saver mode that plays random commits endlessly.

## mgrep

[1:39](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=99)

Up next is M. Grep. And if you've ever wished Grep could understand what you mean instead of what you type, this one's going to blow your mind. MGP is a semantic, multilingual, multimodal search tool that runs straight from the command line. You can search code, images, PDFs, and soon audio and video, all using natural language. No Rayax guesswork. No praying that past developers named things logically.

## Supertonic

[2:05](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=125)

Supertonic, a fast texttospech system built for total privacy running on ONX runtime. Supertonic requires no cloud services, no API calls, and no internet. It can generate speech up to up to 167 times faster than real time on consumer hardware like the M4 Pro. Despite being ultra light at just 66 million parameters, it handles natural text effortlessly. Numbers, dates, currency, abbreviations, complex expressions.

## install-nothing

[2:33](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=153)

Install Nothing is a tiny Rustbased terminal app that simulates installing well, nothing. Run it and you'll get progress bars, fake logs, pretend package lists, the whole installing things vibe without actually changing anything on your system. It's playful and licensed under the extremely permissive do whatever you want with it license. If you love terminal toys, want a fun demo app, or just enjoy confusing your co-workers, install nothing is a perfect little Rust project to start.

## NoteDiscovery

[3:04](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=184)

Note Discovery. If you love tools like Notion or Obsidian, but want total privacy and ownership, this one's for you. Note Discovery is a lightweight, self-hosted knowledge base that gives you full control over your notes, wiks, and second brain, all running on your own server. It's fast, beautiful, and built entirely around plain markdown files. So, there's no lock in or subscription in sight. You get instant search, custom themes, plug-in support, and it works seamlessly across desktop and mobile.

## moss

[3:35](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=215)

MOSS, it's a Linux compatible kernel written in Rust with some Arch 64 assembly sprinkled in for the low-level magic. What makes MOSS stand out is its asynchronous kernel core. Yep, this system uses Rust's async await inside the kernel itself. That means system calls are async, sleep points are compiler verified, and entire classes of classic kernel deadlocks are eliminated. It's cutting edge OS research packed into real working code.

## xleak

[4:03](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=243)

Xleak. If you've ever wanted to open Excel files directly in your terminal, this one's going to blow your mind. Xleak is a fast interactive Excel viewer built with Rust and Ratatouille. turning your terminal into a full spreadsheet viewer. No Microsoft Excel, no guey apps, just pure terminal power. It beautifully renders tables, handles different data types intelligently, and supports every major spreadsheet format. Built on the blazing fast Calamine Excel parser, Xleak turns heavy spreadsheets into a seamless terminal experience.

## Z-Image

[4:38](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=278)

Z image six billion parameter foundation model proving you don't need a monster GPU to get worldclass image generation through smart systematic optimization. Z image delivers photorealistic quality and bilingual text rendering that rivals models 10 times its size and it runs smoothly on consumer GPUs under 16 GB. That means high-end generation is now accessible to everyone.

## Awesome Nano Banana Pro Prompts

Awesome Nano Banana Prompts. An open-source treasure chest with over 500 handpicked prompts built specifically for Google's Nano Banana Pro model. ## s&box

## Depth Anything 3

[5:55](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=355)

Depth anything 3 a model that aims to recover the entire visual space from any view. You don't need fancy multibranch architectures. A single plane transformer backbone and a unified depth ray representation are enough to solve a huge range of geometry tasks. One model can handle monocular depth, multiv- view depth fusion, pose condition depth, and even 3D Gaussian prediction for highfidelity novel view synthesis.

## Nano PDF Editor

[6:23](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=383)

Nano PDF Editor, a command line tool that lets you edit PDF slides using natural language prompts powered by Nano Banana Pro. Want to update a graph with 2025 data or turn a pie chart into a bar chart? Just describe it. Nano PDF editor handles the visuals for you. You can even generate brand new slides that match your deck style, all while keeping your PDF text layer intact through smart OCR rehydration.

## Vex

[6:50](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=410)

Vex, a beautiful Excel and CSV viewer built in Go. Yep, Excel in your terminal, but actually gorgeous. Pick from six stunning themes. Cat Pooin, Nord, Rosé Pine, Tokyo Knight, Groove Box, even Dracula. Navigation, smooth, vim keys, arrow keys, global search, and fast sheet switching. ## History

[7:13](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=433)

This is for everyone who doomscrolls Google Maps at 2 a.m. clicking on random islands asking, "What even is this place?" Because someone finally built the tool we all needed. It's called history, and it lets you click anywhere on a 3D globe, any island, mountain, tiny Arctic village with nine people, and it will actually research the entire history of that location for you. actual research across historical archives, academic papers, and the modern web for up to 10 minutes.

## alt-sendme

[7:45](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=465)

Alt Send Me. Need to send files fast, privately, and without limits? Alt SendMe is a crossplatform peer-to-peer file transfer app that makes sharing files totally frictionless. No accounts, no cloud middlemen, just direct encrypted transfers from your machine to anyone, anywhere. It's powered by IRO for reliablenat hole punching. Quick plus TLS 1.3 for end-to-end security and supports resumable downloads. Think of it as AirDrop for everyone. Open source, unlimited, and totally private.

## FreeMDU

[8:16](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=496)

Free MDU, a project that cracks open the world of Melee appliance diagnostics. MLE has used a hidden infraredbased optical diagnostic interface on their appliances since the '9s, but accessing it traditionally required an expensive proprietary adapter and closed source tooling only available to certified technicians. Freemdu changes that completely provides open hardware, firmware, and software that let anyone communicate with these appliances.

## TONL

[8:46](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=526)

Tonell is a LLM friendly serialization format that can cut your data size by up to 50 to 60% compared to JSON, which also means dramatically lower LM token costs. And unlike binary formats, Tunnel stays completely human readable. But Tunnel isn't just a format. It's a full-blown data platform. You get a JSON path style query API, CRUD modification tools, hashing and bree indexes, and even bit packing for boolean data. It's zero dependencies, built-in pure TypeScript, browser ready at just 10 KB gzipped.

## ESPectre

[9:47](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=587)

Especi Home Assistant or MQTT. No AI models here. Especal analysis to detect motion in real time by reading Wi-Fi channel data. It works through walls, protects your privacy, and turns any smart home into a motionare system. No wearables, no training, just clever physics.

## data-peek

[10:19](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=619)

Data peak, a minimal desktop client for Postgra SQL, MySQL, and SQL Server. If you ever wanted a database viewer that opens in under two seconds and doesn't feel like piloting a spaceship, this is it. You get a Monaco powered query editor with autocomplete, multitab workflows, and even inline editing so you can tweak data directly without firing up heavy gooies.

## JiT

[10:42](https://www.youtube.com/watch?v=K3VYK3AeeT4&t=642)

Next is Jet, just image transformer, a clean re-implementation of idea in generative modeling. What if diffusion models simply predicted clean images again? This project brings the original Jax plus TPU work into PyTorch plus GPU, making it far more accessible to researchers and practitioners. Instead of predicting noise like today's diffusion models do, Jeet argues we should go back to basics and directly model the clean data itself.

## Valdi

true native performance on iOS, Android, and Mac OS? Meet Valdi, an open-source cross-platform UI framework from Snapchat built to end the trade-off between developer speed and runtime performance. Unlike React Native or Flutter, Valdi doesn't rely on web views or JS bridges.
