## Accordion

[0:11](https://www.youtube.com/watch?v=fKRWVWn0QJ4&t=11)

- https://github.com/a-Fig/Accordion

When a coding agent fills its context, the usual fix is compaction, which flattens your whole history into one lossy summary. Accordion shows the agents entire context as a grid of colored blocks and lets you fold the cold parts down by hand or with an automatic conductor. Nothing's deleted and every fold reverses. In one early hackathon run, their conductor cleared 83% of a task against 33% for compaction.

## rift

[0:39](https://www.youtube.com/watch?v=fKRWVWn0QJ4&t=39)

- https://github.com/anomalyco/rift

Git work trees are great until you duplicate a giant repo and wait while dependencies, build artifacts, and local state come along for the ride. Rift is an experimental alternative that creates copyon-write workspaces with file system snapshots and reef links. The maintainers claim under 0.1 seconds on a 10 gigabyte folder. It has a fast CLI, postcreate hooks, shell integration, and a node or bun FFI API.

## brag

[1:06](https://www.youtube.com/watch?v=fKRWVWn0QJ4&t=66)

- https://github.com/latent-spaces/brag

You finally ship the side project, and now the launch post is the hardest part. Bragg is a clawed code skill that turns a finished repo into a short sharable launch video with one command. It picks the product angle, writes the share copy, builds a composition brief, and hands rendering to hyperframes with music and motion included. You get a brag output folder with the plan and MP4.

## recall

[1:31](https://www.youtube.com/watch?v=fKRWVWn0QJ4&t=91)

- https://github.com/raiyanyahya/recall

Every Claw Code session starts cold, so you waste 10 minutes reexlaining where you left off. Most memory plugins fix that by piping your whole transcript, code, and secrets included, off to some model endpoint. Recall keeps it on your machine. It logs each session and condenses it into a resume ready summary with TF and text rank. No LLM call, nothing sent anywhere. Long research runs fail in a boring way.

## Arbor

[1:55](https://www.youtube.com/watch?v=fKRWVWn0QJ4&t=115)

- https://github.com/RUC-NLPIR/Arbor

The agent tries one idea, forgets what failed, and burns the next hour rediscovering it. Arbor turns optimization into a hypothesis tree. It also supports CLI runs, dashboards, and codecs or clawed code skill mode.
