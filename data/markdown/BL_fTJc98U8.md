## text-to-cad

[0:11](https://www.youtube.com/watch?v=BL_fTJc98U8&t=11)

- https://github.com/earthtojake/text-to-cad

CAD tools have a steep learning curve that keeps most software engineers from ever getting into 3D printing. Text to CAD sidesteps the problem entirely. Instead of asking an LLM to reason spatially, the agent writes Python using build 13D and CAD query to generate parts deterministically. Describe what you want. Get precise step, STL, GLB, DXF, and URDF files out. Built-in web viewer previews each iteration.

[0:38](https://www.youtube.com/watch?v=BL_fTJc98U8&t=38)

- https://github.com/openclaw/clawsweeper

Open Claw has 360,000 stars and over 13,000 open issues, most of them outdated, fixed, or AI generated noise.
