## Julep

[0:12](https://www.youtube.com/watch?v=-TT-sHAuljs&t=12)

- https://github.com/julep-ai/julep

Julip is basically Firebase for AI agents. It's an open- source platform for deploying serverless agent-based AI workflows without touching infrastructure. Instead of chaining prompts together, Julip lets you orchestrate complex multi-step agent logic with memory and parallel execution. You can build AI agents that remember past interactions, call external APIs, and scale automatically as usage grows.

[0:38](https://www.youtube.com/watch?v=-TT-sHAuljs&t=38)

- https://github.com/n8n-io/self-hosted-ai-starter-kit

This project is a one-command self-hosted AI lab. The self-hosted AI starter kit is an open- source docker composed setup that instantly spins up a full local AI stack. ## AnyTool

[1:28](https://www.youtube.com/watch?v=-TT-sHAuljs&t=88)

- https://github.com/HKUDS/AnyTool

Any tool is the missing layer between AI agents and real world tools. It's a universal tool use system designed to make agent automation actually reliable in production. ## playwriter

[1:56](https://www.youtube.com/watch?v=-TT-sHAuljs&t=116)

- https://github.com/remorses/playwriter

Playwriter fixes browser automation for AI agents by not overengineering it. Instead of spawning a separate Chrome instance like Playrite MCP, Playwriter runs as a browser extension, letting your AI agent work directly inside your existing Chrome session. That means 90% less context window usage, full access to the entire Playright API, and the ability to collaborate with your agent in real time.
